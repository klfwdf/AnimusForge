# Illustrator 持久维护规则

遵循仓库根 AGENTS.md。颜色修改前必须先读 `docs/color-channel-contract.md`。

## 不得再次引入的颜色错误（2026-09-17 实机反例）

- 已编码 PNG/JPEG 不等于原始 BGRA 显存。`Bitmap.LockBits(Format32bppArgb)` 的内存字节次序，不证明 `Texture.CreateFromMemory(encodedBytes)` 会交换红蓝。
- UI 的 `GauntletTextureLoader.PrepareEncodedImageForUi` 必须保持正常 PNG 的字节/像素；禁止恢复 `SwapRedAndBlueInPng` 或换名的等价转换。产品未发布：彻底删除 `FixColorChannels` 设置、options 字段及 loader 参数，不保留旧配置兼容层，不得仅隐藏开关或改默认值。编码颜色必须是无配置、无调用方覆盖入口的固定契约。
- 图像问题先按同一图像身份对比：原生导出→发送的参考图→服务端/缓存原图→游戏截图。不得仅凭“蓝皮”就改所有通道，不得按肤色统计自动猜测 RGB/BGR。
- 原生导出适配只作用于其已取证的生产者；修改须提供对应导出色块/实际旗帜对照。不得将该适配重复施加到标准缓存、HTTP 结果或 UI 加载。
- 保留红、蓝、金色、肤色、紫色及半透明色块的精确 RGBA 回归；首次加载与缓存重开都要测；反射与全源码扫描必须证明设置、options、修色参数和 PNG 交换函数不存在，实际 UI 加载入口必须调用被测试的准备函数。
- 当前用户图的缓存原色正常，UI 交换错误；不得通过删除缓存或要求付费重绘掩盖显示层缺陷。
- 离线颜色字节测试不能冒充 GPU 实机验收。部署后仍需重启游戏、重新打开旧缓存卡片对照。

## 装备、旗帜与姿态（同日拉盖娅反例）

- 必须保留完整 12 槽快照；`ItemTypeEnum.Banner` 单独记录，不得回落为普通手持武器。装备持有不等于现场可见或必须入画。
- 百科是人物肖像，不是旗帜展示。不得把国王/家族归属、旗帜栏或纹章标准图当成举旗、挂旗的依据；实际盾面/服饰纹章仍须保真。
- 百科默认自然放松姿态、人物为视觉中心。重绘只适度改变镜头/光线，不强制换动作，不以求变化添加桌案与复杂持物。
- 百科专用限制不能全局删除会话/周报里有现场或事件证据的旗帜。
- 文本规则和拒绝回退不能冒充模型最终图像验收。显示层颜色修复不需要重绘；旧图片本身的动作内容需要用户主动重新生成才会改变。

## 最新盾牌规则（2026-09-17，覆盖此前保盾兜底）

用户明确要求减少盾牌，背负也不要：百科默认不画任何盾牌；所有模式禁止背盾、露出背后或肩后的盾轮廓。其他场景只允许有明确实际持盾动作依据的从属盾牌，不把省略的盾变成背景陈设。完整装备仍读取并保留，不可通过删除快照槽来实现；禁止恢复“无持握证据则自然背负”。本条优先于历史交付文档里较早的保盾描述。

## 场景优先与近景半身（2026-09-17 最新追加）

- 百科优先近景半身，保留完整头戴与肩甲，并轮换轻侧半身/中景环境半身。不得以近景为理由删除背景。
- 导演必须输出人物与镜头、场景空间、光线与色彩、空间关系四段具体描述；环境与光线应占主体正文至少一半，不能只罗列装备。结构不足、装备描述压过场景、明确纯黑背景时本地回退，不自动付费重试。
- 背景低对比不等于低曝光。暗部仍需材质、色彩、纵深；不允许黑幕抠像。画风/最高随机度不能覆盖此规则。
- 百科无真实现场时只能明确称为非具名艺术布景；会话/周报依据已有现场事实，不能为丰富背景编造地点、建筑、道具或事件。
- 近景/环境要求不能恢复盾牌、背盾、旗帜或改动完整装备、固定 RGB 显示契约。
