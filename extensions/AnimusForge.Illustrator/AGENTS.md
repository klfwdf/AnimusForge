# Illustrator 持久维护规则

## 场景喊话 / 战斗双截图（2026-10-08 用户授权）

- 独立手动按钮模式：只采当前屏幕和绕人物/交互区域反侧回望的两张真实截图，不调用全景、立绘或普通会话截图入口。用户允许短暂隐藏 UI、冻结现场和切镜，第二张完成即恢复原相机/UI/暂停状态；没有旋转动画，后台不再碰相机。
- 两图都必须送识图导演和带图生图；普通参考图/识图开关不能令本模式丢图，导演关闭/未配置、采集失败、重复图或接口失败均明确停止，不退文生图、不本地构图替代、不自动重试。战斗保留采集动作，喊话冻结最近两轮完整已发送/收到多人对白；保持相对站位距离朝向，构图可重选。
- 采集未完离场终止；采完关闭面板/离场继续后台保存，只有原 Mission、原 Screen 和原面板仍在时可展示成图。未完成禁止重复点击；原普通会话禁截图规则保持。
- 沿用模型、画风、尺寸与画廊。原统一双 API/Bootstrap 构建和专项采集/传输 fixture 分层验证；不运行既有 Illustrator 离线审计脚本、不调用付费 API，不部署/打包/推送。原生截图帧/HUD/相机恢复及真实出图须单独实机验收。

## 重绘（基于本图）（2026-10-08 用户授权）

- 与普通重绘、带提示词重绘独立：只用当前显示的成图和玩家修改要求，直接调用生图模型，不调用或要求配置导演，不重新采集游戏现场。此模式不注入原事实、画风、负面偏好、随机变化或参考图完整重画指令；保留当前面板输出画幅。
- 必须上传一张GeneratedImage底图，忽略普通生成的参考图开关但不改设置；Edits、Chat多模态及Player2沿对应带图通道，不能丢图回退到文生图或自动付费重试。
- 提交冻结底图和请求设置；新成图独立存档并记录来源Key/修改要求/模式，旧缓存兼容，失败保留旧图和草稿。画廊暂不加编辑入口，场景喊话及战斗截图生图另行授权。
- 本次按源码链路/布局绑定检查和原统一双版本构建验证，不运行Illustrator离线审计、不调用付费API、不部署/打包/推送。


## 导演输出预算与可选强制缩减（2026-10-07 用户授权）

- 本条覆盖历史“导演请求不发送硬 max_tokens”：新增 DirectorApiMaxTokens，默认25000、512–64000，实际写入导演请求。旧 DirectorMaxTokens 继续表示约Token参考篇幅，不迁移成API预算，不能要求模型用满输出预算。
- 最大输出设置下方提供强制缩减开关，默认关闭；字符上限默认4000、1000–32000。开启时导演收到简洁正文要求，Images/Edits/Chat及既有协议回退共用请求快照中的上限；关闭保持原模型限制与32000字符安全上限。
- 复用已有 ImagePromptBudget，仅缩减可裁剪的导演四段，保留事实区、固定画幅、画风和参考图说明；无法满足时停止发送。字符限制不等于token预算，不新增模型调用、自动重试、Tick工作或后台游戏对象读取。
- 设置由既有MCM序列化保存，每请求冻结；本轮按源码审查和原入口双版本编译验收，不运行Illustrator离线审计脚本。不自动调用付费API、部署、打包或推送；空回根因与模型遵从仍须真实响应验证。

## 全屏与快报固定画幅（2026-10-07 用户确认）

- 全屏场景插画和快报共用16:9尺寸映射，并在请求快照携带独立画幅约束；最终Images/Edits/Chat提示词及已有协议回退都须固定注入，不能依赖导演复述。普通生成、自动重绘、带提示词重绘均保留输出画幅；该展示格式要求不恢复被玩家重绘要求覆盖的旧事实、画风或禁物。
- 用户追加百科/独立面板同样要遵循MCM尺寸：全部生成请求按实际ImageSize生成固定画幅说明，1024x1024明确正方形1:1，其他档位用宽高最大公约数得到准确比例（1344x768为7:4）；全屏/快报仍先映射16:9再生成说明。普通生成和重绘都保留，不依赖导演。
- 固定画幅说明计入最终32000字符预算且不属于可裁剪的导演四段。不修改共享MCM尺寸，不裁剪/拉伸旧成图，不自动付费重试。已发送尺寸和文字要求仍不等于服务端最终比例已经验收。

## 模组内存储与显式 API 测试（2026-10-06 用户授权）

- 生图自行写入的成图/诊断保持logs/image save，临时导出使用Cache/Illustrator/Temp，MCM生图设置/预设与模型列表缓存使用Configs/Illustrator；全部由当前模组根解析，不回退Windows Temp、AppData、Documents或进程目录。
- 用户随后明确“不迁移”：不读取、复制或迁移Documents/AppData/Temp旧生图配置和缓存。模块无配置时使用默认并由玩家填写API；旧文件保留。不得输出API密钥到日志/公告/包。MCM路径适配只命中生图设置，不能全局改其他模组保存位置；失败不得静默回写C盘。
- 自动清理默认true，已有显式配置保留；清理范围沿用当前请求临时文件，不清画廊/历史或全局Temp。不得为改路径改变原生渲染/颜色/资源清理顺序。
- MCM测试按钮仅玩家显式点击发起请求，标明可能计费，复用真实生图客户端并禁止该测试的自动通道重试；以当前UI配置生成脱离游戏状态的请求快照，支持取消/超时和有界worker。测试图只覆盖模组ApiTest/last-result.png，不写游戏记忆/画廊，不自动调用付费服务验收。

## 本次玩家重绘要求优先（2026-10-06 用户明确授权）

- 仅在“重绘（带提示词）”时，本次明确的视觉要求高于原资料、参考图、模式默认禁物、MCM长期画风/负面偏好及旧画变化建议。要求加剑时，即使百科默认禁武器或原装备没有剑，也应由导演写入并交给生图。此条在冲突部分覆盖下文历史约束；普通生成、无提示词重绘保持原约束。
- 只改玩家明确指定的方面；未指定的身份、外貌、服饰、场景、画风仍沿用原资料。该变化只属于本幅图的艺术改编，不写回游戏装备、事实、记忆或存档。
- 原输入只交导演，导演按原四段/元数据协议转为确定画面；原游戏事实与参考图仍完整提供给导演。最终生图采用协调后的正文，不重新追加已被要求覆盖的原事实/固定禁物；Chat/Edits参考标签服从本次方案。既有导演不可用、空回复/截断、取消和无自动付费重试边界保留。
- 保存的画风和自定义负面偏好仍输入导演；带提示词重绘不把旧画风API参数、固定画风锚点、固定负面偏好或随机指导重新强加给最终生图。请求快照不改MCM值，不污染下一次普通生成；图像质量、格式和现有通用成图缺陷负面词保留。
- 生图总超时仍为MCM每次请求冻结的60–600秒（默认240），不改导演独立240秒或采集预算。记录image_budget/timeoutMs，不记录密钥。本次按源码审查与原入口双版本编译验证，不运行Illustrator离线审计脚本；实际模型遵从和MCM实机改值计时仍须明确实测。

颜色修改前必须先读 `docs/color-channel-contract.md`。

## 当前普通NPC年龄（2026-09-22）

- 普通会话NPC的年龄、身体参数和现场装备绑定当前 `OneToOneConversationAgent`，不能以同一CharacterObject兵种模板匹配代替具体实例。年龄直接来自同一冻结BodyProperties的Age，不经字符串解析后回落模板；无实例或无有效值保持未知。Mission中未取得具体实例装备时停止，不冒充大地图模板回退。大地图无现场Agent时原装备/立绘路径保留，年龄标未知。
- 每请求在既有诊断记录 `conversation_npc_age`：实例编号、原始年龄、提示词年龄、来源与立绘身体参数；只存托管快照，不新增Tick或场景扫描。游戏年龄不能用于补造参考图没有的白发、皱纹、松弛或佝偻，不凭照片观感把真实数值改小。旧日志缺少原始年龄时必须说明证据边界。

## 会话背景人群与行动（2026-09-22）

- 会话人群依据来自既有附近Agent统计，必须标记真实来源并区分已排除的对话对象；多份名单不累加人数。职业仅证明身份与在场，不证明擦杯、端盘、乐器、服装或具体劳动；位置缺失/扫描失败保持未知，零人不得用酒馆等场所模板补满。周报不借用当前现场人群，百科不接入会话人群事实。
- 导演按在场证据和选定机位组织背景活动，不默认空场或一律模糊人影；保留墙体、楼层、遮挡及人数边界。生图端的独立副本透视参考须说明主动省略人物和动态实体，空桌椅不等于现场无人。
- 已发生动作优先描绘进行中及双方反应，邀请/计划/拒绝不能升级为已接受、已完成动作。保留自然静态，不强迫复杂动作。
- 附近物体名称中的生成点/动画点只在文字事实入口过滤，且在最近20项筛选前过滤；不得据此剪掉原生几何、修改全景采集/投影或新增扫描。真实陈设仍由现场实例及参考图确认。

## 不得再次引入的颜色错误（2026-09-17 实机反例）

- 已编码 PNG/JPEG 不等于原始 BGRA 显存。`Bitmap.LockBits(Format32bppArgb)` 的内存字节次序，不证明 `Texture.CreateFromMemory(encodedBytes)` 会交换红蓝。
- UI 的 `GauntletTextureLoader.PrepareEncodedImageForUi` 必须保持正常 PNG 的字节/像素；禁止恢复 `SwapRedAndBlueInPng` 或换名的等价转换。产品未发布：彻底删除 `FixColorChannels` 设置、options 字段及 loader 参数，不保留旧配置兼容层，不得仅隐藏开关或改默认值。编码颜色必须是无配置、无调用方覆盖入口的固定契约。
- 图像问题先按同一图像身份对比：原生导出→发送的参考图→服务端/缓存原图→游戏截图。不得仅凭“蓝皮”就改所有通道，不得按肤色统计自动猜测 RGB/BGR。
- 原生导出适配只作用于其已取证的生产者；修改须提供对应导出色块/实际旗帜对照。不得将该适配重复施加到标准缓存、HTTP 结果或 UI 加载。
- 保留红、蓝、金色、肤色、紫色及半透明色块的精确 RGBA 回归；首次加载与缓存重开都要测；反射与全源码扫描必须证明设置、options、修色参数和 PNG 交换函数不存在，实际 UI 加载入口必须调用被测试的准备函数。
- 当前用户图的缓存原色正常，UI 交换错误；不得通过删除缓存或要求付费重绘掩盖显示层缺陷。
- 离线颜色字节测试不能冒充 GPU 实机验收。部署后仍需重启游戏、重新打开旧缓存卡片对照。

## 装备、旗帜与姿态（同日拉盖娅反例）

- 必须保留完整 12 槽快照；`ItemTypeEnum.Banner` 单独记录，不得回落为普通手持武器。装备持有不等于现场可见或必须入画。**例外（2026-09-18 用户指定）：百科肖像在装备快照阶段即清空全部武器槽**（武器、盾牌、旗帜均不入画），事实区与离屏立绘同步无武器——装甲服饰保留；此清空仅作用于百科链路，会话/周报仍用完整快照。
- 百科是人物肖像，不是旗帜展示。不得把国王/家族归属、旗帜栏或纹章标准图当成举旗、挂旗的依据；实际盾面/服饰纹章仍须保真。
- 百科姿态与构图由导演自主推导。**2026-09-18 用户要求修复怪姿势与 Edits 抠图换背景，覆盖此前强制反站姿/每次换姿势规则**：自然可信优先，允许站立、坐姿或延续合理体态；重绘优先通过镜头、取景、光线或场景层次形成变化，不能强迫跨坐、踮脚、扭腰或多支点撑扶。参考图锁定身份与实际穿戴，不锁定原图像素、光照和轮廓；导演须说明机位、朝向和受光，生图端须将人物和环境统一重新绘制，而非只换背景。坐靠须有真实支撑。Chat 与 Edits 均需收到整幅重绘及参考图用途说明；不得把全透明 mask 视为“仅参考身份”的保证或自动附加该 mask。仅人物身份、装备、纹章等事实保持锁定，不编造不存在的装备。
- 百科专用限制不能全局删除会话/周报里有现场或事件证据的旗帜。
- 文本规则和拒绝回退不能冒充模型最终图像验收。显示层颜色修复不需要重绘；旧图片本身的动作内容需要用户主动重新生成才会改变。

## 行动优先与作品命名（2026-09-18 后续用户要求）

- 导演先决定人物此刻正在做什么，再推导姿态、手部动作、视线及镜头。保留自然站姿，但不能默认双手下垂展示装备；不强迫复杂动作。此条覆盖上文优先只换镜头/光线的重绘指导。
- 重绘读取同存档、同人物或同事件最近三张的行动摘要；百科减少重复展示姿势，会话/周报不能为去重改变当前事实。旧缓存可从人物与镜头段提取参考，历史行动不能当作现场事实。
- 导演同时给出标题与主题，单独保存和展示，不混入生图正文或当作画中文字。负面词只保留简短通用缺陷及选定画风所需排除词，不全局禁止露脸或添加面具专用限制。

## 画风与须发保真（2026-09-19）

- 古典油画预设统一维护：导演读具体的完整画法，生图端只追加简短画风要求；本地回退同样使用短版，不把导演说明整段重复给生图。用户已保存的自定义文本不得自动覆盖。
- 发色参数是种族色板中的偏移，不是通用金/棕/黑色编码；不得由色值、年龄、性别、文化或身份推断卷发、披发、盘发、胡须样式、白发。须发有无及可见形状以对应人物原始参考为准，装备遮发/遮须标记分别保留；秃头、无须、非人类不能套通用人类模板。
- 普通 NPC 的未知年龄不得硬填 28 岁或套壮年战士体格。参考图不足以辨认的细节保持未知，不让上一张生成图成为新的外观事实。

## 最新盾牌规则（2026-09-17，覆盖此前保盾兜底）

用户明确要求减少盾牌，背负也不要：百科默认不画任何盾牌；所有模式禁止背盾、露出背后或肩后的盾轮廓。其他场景只允许有明确实际持盾动作依据的从属盾牌，不把省略的盾变成背景陈设。完整装备仍读取并保留，不可通过删除快照槽来实现；禁止恢复“无持握证据则自然背负”。本条优先于历史交付文档里较早的保盾描述。

## 五项优化（2026-09-19 用户确认全部实施）
