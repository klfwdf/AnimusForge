# 外交事件节奏、MCM与回应修复（2026-10-06）

普通自动外交与政策触发共用同时进行的事件上限，默认3场，可调1—12；每天最多新开一场普通事件。当天开场日期持久保存，关闭或失败不退还当日名额，读档不会同日重复开场。旧档首次从普通事件起始日期初始化；旧开场间隔字段继续兼容，但不再显示或控制调度。

政策满额时保留待办，仍可合并到已有交涉；合并不占新开场。降低上限不取消正在进行的事件，也不阻止现有回应。玩家主动外交和口头承诺独立。
