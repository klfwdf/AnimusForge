# 外交回应与回合生命周期修复（2026-10-08）

玩家回复已经结束的外交事件时，通过原回应入口建立独立回合，保留来源公文作为背景，不复活过期提案。解析期间原回合关闭、结算容量不足或读档发现归属缺失时，同一公文、分析任务与传播记录转入可用回合；根公文解析完成后才启动接力规划。提交与弹窗打开时重新检查玩家权限和文书归属。

回合硬截止和自动熔断只等待实际运行中的请求；关闭时清理失效任务与待回应标记，真实 HTTP 租约保留到请求完成。正式条约解析保留附加期限、贡金和领地字段，由权威检查明确拒绝不支持的内容，避免丢弃附加条款后错误接受原案。

这些检查在提交、分析完成、关闭和读档边界执行，没有新增逐帧档案扫描或额外 LLM 请求链。存档键、Schema、模块身份、默认交互入口和原一键构建流程保持。
