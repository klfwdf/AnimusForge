结构
1. 原生王国导航：去掉“议程”“派系”两个页签，合并为“内政”（选中态沿用派系页签红底金边）
2. 王国态势带：沿用 v5（旗帜/身份 | 稳定度 | 军力分布）
3. 内政主区 = 左侧目录 380 + 右侧羊皮纸卷宗
   - 目录头：标题“内政事务” + 王国切换（对应 VoteDealBehavior 的 KingdomSelector 上/下一王国）
   - 分组“王国议程”：每条议程一行（图标/标题/类型·发起人/剩余天数或“你的提案”角标）
   - 分组“派系与阵营”：各派系（色点）、王室阵营、未表态（原 v5 顶部页签改为目录行）
   - 脚注：议程与派系不满的联动说明
4. 卷宗（议程选中时）：类型标签+发起信息 → 议程标题/说明 → 右侧“距离表决 N 日”
   → 左：选项与票势（支持率条、领先/你的倾向标记）+ 派系影响提示条
   → 右：家族表态表（家族/支持/权重/派系）→ 脚注（最新纪事、拉票计数）
   选中派系目录行时，卷宗换回 v5 派系卷宗内容（诉求头/进程/成员表）
5. 身份操作栏：随选中对象切换；议程选中时为 支持选项 / 召开投票会议 / 提前裁决 / 推翻表决

未做：派系选中态画板、非国王视角、无议程空态。数据均为演示数据。未改任何代码。
