# Expedition Parade / 出征阅兵 — AF 阶段 0

需求来源：`G:\A=MY MOD\HANDOFF.md`（只读参考；未修改原文件）。

## 当前落地范围

- 在城镇、城堡、村庄菜单注册“出征阅兵：勘测路线（阶段 0）”。
- 所有菜单状态统一调用 `ParadeEligibilityService.CanStartParade(...)`。
- 村庄权限跟随绑定的城镇/城堡；普通封臣不能在其他家族领地使用；本国统治者可以在本国领地使用。
- 从玩家主队伍创建只读健康普通士兵快照；排除英雄、同伴与伤兵；展示计划使用确定性的最大余数比例抽样，且不超过真实人数。
- 进入正常 `center` / `village_center` Mission 后只做一次只读探针：记录场景名、Location、实体候选、脚本、标签、导航面、边界、可达路径和退出带候选。
- 不生成 Agent、不修改部队、不接管平民、不修改聚落、不写入存档。

## 专用锚点契约

若场景覆盖已提供以下三个标签，探针会验证完整的 `Spawn -> Gate -> Exit` 导航路径：

- `af_parade_spawn`
- `af_parade_gate`
- `af_parade_exit`

三个锚点都必须在可用导航网格上，且三段路径均可达。没有专用锚点时，探针只输出候选证据，不会把名称猜测当成已验证路线。

## 游戏内验证步骤

1. 在玩家/玩家家族拥有的城镇进入聚落菜单，确认入口可用。
2. 在同王国其他家族领地以普通封臣身份确认入口禁用且有原因。
3. 以统治者身份确认本国其他家族领地可用。
4. 分别在城镇、城堡、村庄运行一次探针并正常退出 Mission。
5. 在 AF 日志中筛选 `ExpeditionParade`，保存 `Probe summary`、`Probe candidate`、`Probe boundary`、`Probe route status`。
6. 根据实际实体/标签证据建立首批三个场景的专用锚点后，再实现生成与行军纵向切片。
