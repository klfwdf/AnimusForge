 AnimusForge 群友问答知识库
 版本范围：以 2026-08-31（v1.3.7.2）为基线，整理 2026 年 9 月 1 日之后的 1.5 累计更新。
 用途：供机器人回答群友问题。回答时优先给出“结论”，再补充操作步骤和限制。
 
 ====================
 一、模组是什么
 ====================
 
 问：AnimusForge 是什么？
 答：AnimusForge 是《骑马与砍杀 2：霸主》的 LLM 互动模组。它把 NPC 对话、场景喊话、信使、政策、外交、处决、政变、快报和记忆系统连接起来，让 NPC 的回答和游戏中真实发生的事件相关。
 
 问：必须使用 AI API 吗？
 答：文字对话和大多数 LLM 功能需要配置文字 API。AI 画卷需要另外配置生图 API。不配置生图 API 不影响普通文字对话；不配置文字 API 时，相关 AI 对话和生成内容无法工作。
 
 问：支持哪些游戏版本？
 答：发布包包含 Bannerlord 1.3 和 1.4 两套实现，启动器会按游戏版本选择。不要把两套 AnimusForge DLL 同时放进游戏目录。
 
 ====================
 二、主要功能
 ====================
 
 1. 公开处决
 - 从裁决、刑罚选择、刑场布置到现场执行的完整流程。
 - 支持开场、行刑中、结束后三阶段发言和最后陈述。
 - 可通过场景喊话或直接对话向本场刽子手下令。
 - 否定句、疑问句、条件句不会被当作立即执行命令；信使不能远程启动刑场。
 - 只有实际显示出来的发言才会写入记录；开始行刑不等于已经死亡。
 - 最近 100 场处决实录可保留在记录中。
 - 公开处决的入口和对象受游戏条件限制，不是对任意人物无条件开放。
 
 2. 宣权篡位
 - 符合条件时，玩家可在本国国王所在城镇发动行动。
 - 玩家带领真实部队进行街道战斗，再从幸存者中选择队伍攻入大厅。
 - 默认门槛：家族等级 4、影响力 300、60 名健康普通士兵，另留 1 人接应。
 - 影响力门槛默认只检查，不直接扣除；玩家、英雄和伤兵不计入普通士兵门槛。
 - 街道突击队、大厅突击队、守卫、护卫、守军波次和增援间隔都可在 MCM 调整。
 - 夺取大厅不等于所有家族立即服从；胜利后的处置和政治结算仍需玩家确认。
 - 关闭总开关只禁止新的发动，已经开始的战斗会安全收尾。
 
 3. 王国内战与派系
 - 可启用内战派系，让处决、封地落选、强推政策、强推战争或和约、领地遭劫等事件积累不满。
 - 可在政治面板查看派系和诉求。
 - 玩家可以创建派系、解散派系、更改诉求、满足条件后手动起兵。
 - 玩家派系不会自动替玩家招募成员或擅自起兵。
 - 可调整成派不满阈值、最后通牒间隔、最长内战周数、派系冷却、派系数量上限、同时内战和手动起兵条件。
 - 正式封臣玩家不会再被误判为没有参与资格；佣兵等原有限制仍然有效。
 
 4. 政策、投票与定居点
 - 政策可影响村庄生产、部队规模、招募、领主和封臣关系等。
 - 可启用“领主投票考虑利益、关系与性格”。
 - 投票可分别调整利益、关系、性格三项权重；默认权重为 1.00，范围为 0 到 3。
 - 政策档案可查看当前状态、效果、剩余时间、费用和反馈。
 - 可调整城市、城堡繁荣度上限，村庄户数上限，城市/城堡/村庄民兵上限，以及城市/城堡粮食容量。
 - 默认只开启粮仓容量调整，城市和城堡最终容量默认均为 1000；其他上限默认关闭。
 - 上限只限制总量；超过上限的数值不会被强行削减，正增长暂停，负增长仍会生效。
 - 使用第三方粮食模型时，部分容量和上限调整可能无法应用。
 
 5. 外交
 - NPC 的外交口头承诺可以记录、修订并写入记忆。
 - 多个外交事件可以同时推进，玩家回应会统一排程。
 - 外交文书公开后，相关人物会立即知晓。
 - 对话规则中有独立的外交识别入口。
 
 6. 对话界面与场景喊话
 - 可启用 AnimusForge 羊皮纸风格对话界面，带人物头像。
 - 场景喊话面板有三种风格：原样、卷轴式、右侧手札。
 - 卷轴式和右侧手札支持按住框选、松开展开轮盘，并进入持续的场景多人会话。
 - 可启用自动进入 AI 模式，并设置为仅 Hero 自动进入。
 - 原版对话和 AI 对话正文分开保存，不会互相覆盖。
 - 场景喊话支持召唤、带路、跟随等动作；动作必须满足对象、场景和规则条件。
 - NPC 回复生成时不能切换普通模式；生成期间点击“继续”不会打断当前回复。
 - 长的原版对话选项可以滚动，输入框和继续按钮的误触问题已修复。
 
 7. AI 画卷
 - 可为会面和事件生成插画，也可在画廊浏览并把作品转成 RP 物品。
 - 生图 API 与视觉导演 API 可以分开配置；导演 API 留空时可复用文字 API。
 - 支持模型、端点、密钥、分辨率、画质、画风、负面提示词、随机度、参考图、离屏环境渲染和本地缓存数量设置。
 - 可启用自动生图和 NPC 回复后的自动重绘；自动重绘需要先手动生成本次对话的首张图。
 - 重绘时可以输入本次指导意见。导演无法执行指导时会停止，不会悄悄按原样再画。
 - 野外会区分战前接触、行军相遇、战后处置俘虏和部队界面交谈，不再全部画成战前谈判。
 - 部队界面与 NPC 交谈时不做全景采集，以减少卡顿。
 - 生图速度、画质和费用取决于所选服务与模型。
 
 8. 快报、周报与信使
 - 可启用“即时快报”替代每周长周报。
 - 即时快报会收集约 1 天的大事合写成一篇，每期默认只调用 1 次 LLM，发出后冷却 3 天。
 - 世界快报、王国档案、国家筛选、日期排序、消息去重和重新打开快报均已支持。
 - 信使来信、回信和写信界面可使用国家信纸样式。
 - 快报依据确认发生的事件，不会把局部胜利写成击败整支围城军团。
 - 城镇记忆按确认事件更新，刷新间隔为 7 个战役日。
 
 9. 终端、API 与检索
 - U 键或大地图按钮可打开图形化终端，集中查看设置、战争统计、快报和周报。
 - 游戏内 API 引导提供 YJ、DeepSeek Flash、DeepSeek Pro 等预设，也支持自定义 API。
 - 主 API 支持流式传输开关，默认关闭。
 - 模型列表可实时拉取刷新；模型下拉会按模型名恢复选择，不再只按保存序号。
 - 可选 CUDA 重排序推理设备：默认 CPU，也可切换 NVIDIA CUDA；需要另装 CUDA 运行组件，修改后需要重启，失败时回退 CPU。
 - CUDA 重排序只影响检索排序，不等于让所有 LLM 推理使用 GPU。
 
 ====================
 三、安装与设置
 ====================
 
 问：应该安装几个 AnimusForge 模块？
 答：只安装一个 AnimusForge 模块。发布包内部包含 1.3 和 1.4 两套实现，由 Bootstrap 按游戏版本选择。不要同时安装旧的 AnimusForge_Illustrator、AnimusForge_DialogueUI、AnimusForge_Coup 独立副本。
 
 问：需要哪些前置？
 答：通常需要与当前 Bannerlord 版本匹配的 Harmony、ButterLib、UIExtenderEx、MCM 等前置。具体以发布包说明和当前游戏版本为准。
 
 问：升级前要做什么？
 答：备份存档、MCM 设置、世界书和自定义内容；保留已有 ONNX 模型文件。升级后先确认模块只加载一次，再测试 API、场景喊话、快报和存档读取。
 
 问：文字 API 和生图 API 是一回事吗？
 答：不是。文字 API 用于 NPC 对话、规则判断、快报等；生图 API 用于插画。两者需要分别配置。
 
 问：怎么打开终端？
 答：默认使用 U 键，也可以通过大地图按钮进入。战争统计、快报和周报都集中在终端中。
 
 问：为什么 AI 画卷不生成？
 答：依次检查：是否启用生图总开关；端点、密钥和模型是否正确；服务是否支持对应接口；是否配置了视觉导演 API；是否仍在生成或被缓存/退出战役取消。没有生图配置时，普通文字对话仍可使用。
 
 问：为什么 CUDA 没有生效？
 答：CUDA 重排序只支持 NVIDIA 显卡，需要额外安装可选 CUDA 运行组件，并在修改后重启。组件缺失或初始化失败时会回退到 CPU。它只影响重排序，不负责普通 LLM 推理。
 
 ====================
 四、常见问题与排查
 ====================
 
 问：我说了命令，NPC 没有执行，为什么？
 答：自然语言只是提出意图，必须同时满足话题规则、对象资格、场景条件、权限、同意规则和后处理标签。请明确说出对象和动作，并确认目标人物当前在场。涉及场景移动时，目标必须是当前场景 NPC/Agent，不是只写一个坐标。
 
 问：刽子手不执行我的命令，怎么办？
 答：必须在当前刑场对本场刽子手下令。否定句、疑问句或条件句不会直接执行，信使也不能远程启动。确认命令后，当前版本不需要再额外点击一次“离开”。
 
 问：政变为什么不能发动？
 答：检查是否启用总开关、地点是否为本国国王所在城镇、家族等级和影响力是否达标、是否有足够健康普通士兵。玩家、英雄和伤兵不计入普通士兵门槛。
 
 问：内战为什么没有立刻爆发？
 答：内战有不满阈值、最后通牒、军力和冷却条件，不是每次事件立即起兵。玩家派系默认不会自动替玩家招募或起兵，需要在条件满足后手动操作。
 
 问：快报写错了战斗结果，怎么办？
 答：先确认使用的是新版本并等待事件确认。快报依据确认发生的事件，旧消息或旧档可能保留历史数据。反馈时提供存档、事件时间、参战部队和相关日志。
 
 问：NPC 记不住之前发生的事？
 答：只有实际发生并成功写入记忆的事件才会被引用。未显示的草稿回复、被取消的会话和未完成的异步回复不会强行写入。自由对话、场景喊话和信使应使用同一套记忆；若只有一个渠道记得，通常属于同步或配置问题。
 
 问：场景喊话为什么没有反应或没有移动？
 答：确认场景喊话开关、目标 NPC 是否在当前场景、目标是否可识别、是否满足距离和权限条件。带路/召唤/跟随使用当前场景 Agent 作为目标，不能只对不存在的坐标发命令。
 
 问：对话中点击“继续”没有反应？
 答：如果 NPC 回复正在生成，继续按钮会被锁定，避免打断本轮生成。等回复结束后再继续。普通对话输入框空白区域无法继续的问题已修复。
 
 问：模型下拉框总是跳回另一个模型？
 答：新版按模型名称保存和恢复选择。升级后重新拉取一次模型列表并保存设置；仍异常时提供 MCM 配置和日志。
 
 问：升级后出现重复模块、重复 UI 或重复动作？
 答：检查 Modules 目录是否同时存在 AnimusForge 主模块和旧的 Illustrator、DialogueUI、Coup 独立模块。只保留一个主 AnimusForge 模块及正确前置。
 
 问：旧存档能不能直接用？
 答：通常可以尝试，但重大机制、旧设置、旧记忆和第三方模组状态可能影响结果。升级前必须备份；遇到问题请用备份档复现，并说明是否为旧档。
 
 问：出现报错弹窗怎么办？
 答：先记录游戏版本、AnimusForge 版本、启用模块、发生地点、操作步骤、是否旧档、API 类型和相关日志。不要只发截图，也不要公开 API 密钥。若提示发生在异步回复结束后，说明是否同时切换了对话、离开场景或读档。
 
 ====================
 五、机器人回答规则
 ====================
 
 1. 不要承诺“任何 NPC、任何场景、任何时候都能执行”。先说明条件、对象和权限。
 2. 不要把“开始行刑”回答成“已经死亡”，两者是不同事件。
 3. 不要把关闭功能回答成删除旧存档或回滚已发生事件；关闭通常只影响新触发。
 4. 不要把文字 API、生图 API、CUDA 重排序混为一谈。
 5. 不确定具体设置名称、默认值或兼容性时，回答“需要确认版本和 MCM 页面”，不要猜。
 6. 排查问题时优先索要：游戏版本、模组版本、前置列表、存档类型、复现步骤、日志。
 7. 提醒用户删除日志和截图中的 API 密钥、令牌、个人路径等敏感信息。
 8. 本文整理的是玩家可见功能和常见问题，不代表所有内部测试、重构和未完成实验功能都已发布。

六、全模组功能地图
====================

AF 核心对话：主/辅助/后处理/事件 API、规则检索、知识库、NPC 人格背景、对话历史、每日记忆、记忆压缩、事实写入、信使、自由对话和场景喊话。
AF.Module.Diplomacy：王国议程、政策提案、投票、领主利益/关系/性格评议、外交事件、文书、口头承诺、宣战、和平、贸易、联盟和附庸。
AF.Module.Policy：自定义政策、政策效果模块、村庄生产、部队上限、士兵经验、招募、繁荣/民兵/粮仓容量、政策生命周期和政策档案。
AF.Module.Weekly：周报、即时快报、世界快报、王国/国家档案、排序筛选、去重、事件配图和信使回信。
AF.Module.Conversation：场景喊话、自由对话、NPC 主动发言、对话历史、场景动作、记忆/事实写入、异步回复隔离。
AF.Module.Taunt / SceneActions：挑衅、吵架升级、和平场景冲突、带路、召唤、跟随、战场演讲、观众回应、NPC 站位和战术推进。
AnimusForge.SiegeAftermathIntervention（GCCZ）：城镇/村庄战乱介入、屠杀、掠夺、殖民、地方治理、居民反应、战利品、繁荣恢复、俘虏处置和文化记忆。
AnimusForge.Coup：宣权篡位、街道/大厅突击、真实守军分波、国王处置、加冕、战报和增援控制。
AnimusForge.DialogueUI：羊皮纸对话界面、场景喊话面板、原样/卷轴式/右侧手札、自动 AI、仅 Hero 自动 AI、历史删除按钮和原版回退。
AnimusForge.Illustrator：百科/会面/快报插画、生图 API、视觉导演、参考图、环境全景、自动/定向重绘、画廊、RP 物品和缓存。
AF 终端与存档：U 键终端、战争统计、快报/周报浏览、API 引导、配置迁移、存档持久化、日志、性能监控、卡死线程 Dump 和数据管理。

====================
八、全模组回答规则
====================

具体设置名称、默认值和选项会随版本变化；无法确认时要求玩家提供游戏版本、AnimusForge 版本和 MCM 页面。
关闭开关通常只阻止新触发，不会回滚已经发生的战斗、死亡、交易、记忆、外交或政策结果。
主 API、辅助 API、后处理 API、事件/叛乱 API、生图 API、视觉导演 API、Reranker API 用途不同，不能混为一谈。
