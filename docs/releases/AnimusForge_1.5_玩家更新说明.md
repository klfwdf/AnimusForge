# AnimusForge 1.5 更新公告

**发布日期：2026 年 10 月 2 日**
**适用内容：相较 2026 年 9 月 6 日之前版本的累计更新。**

各位领主，好久不见！

距离上一次更新已经接近一个月。这次 1.5 不只是修补旧功能：我们把公开处决、宣权篡位、新对话界面与 AI 画卷整合进了 AnimusForge，同时补上内战派系的玩家操作，并改善快报、周报、信使和 AI 对话的衔接。

你可以在刑场上听到最后陈述、向刽子手下达命令；可以带领突击队从城镇街道攻入大厅，争夺王位；也可以在王国政治中组织自己的派系、调整诉求，决定何时起兵。人物的回应、现场的记录与后续报道，会围绕实际发生的事件连接起来。

下面是本次累计更新的主要内容。

---

## 一、公开处决：从判决到刑场，不再只有一个按钮

公开处决作为完整玩法接入本体。它不只是处决后弹出一段文字，而是包含罪名与裁决、刑罚选择、刑场布置、现场执行及事件留存的一整套流程。

### 完整的刑场流程

- 可按系统允许的对象与条件进行裁决、选择刑罚，并进入实际刑场；并非对任意人物无条件开放处决。
- 提供多种刑罚方式，以及自定义刑场的布置与预设能力。不同选择会影响贵族与平民的认可、安全度、忠诚度等结果，不只是更换演出。
- 支持连续行刑，让同一场处决能够按顺序处理多个对象。
- 轮刑已从新的刑罚选择列表中隐藏；旧记录和旧预设中的相关身份仍保留，不直接清空已有数据。

### 人物会在现场发言

- 发言区分**开场、行刑中、结束后**三个阶段，并结合人物、案件与已有记忆组织内容。
- 增加专门的**最后陈述**环节。玩家可以听完，也可以提前下令，不必被整段遗言强制拖住。
- 可以向**本场刽子手**通过场景喊话或直接对话下达行刑命令。否定句、疑问句、条件句不会被当作立即执行的命令；信使不能远程启动刑场。
- 修复非流式回复、空流回复与较长发言的阶段处理，减少有回复却没有正确呈现的情况。

### 发生过的事才会留下记录

- 现场真正显示出来的发言才写入记录，没有说出口的内容不会事后补造。
- 已死亡人物不会继续发言；进入后续阶段时不会把未完成的台词强行补播。
- 现场记录与符合条件听众的记忆相衔接，并保留最近 **100 场**处决实录。
- 快报与周报依据确认结果传播事件：**开始行刑不等于已经死亡**，不会仅凭一句命令就提前写成死亡新闻。

## 二、宣权篡位：亲自带兵争夺王位

新增并整合武装政变玩法。符合条件时，可以在本国国王所在城镇发动行动，带领实际部队进入街道战斗，再从幸存者中选择队伍攻入大厅。

### 发动与推进

- 默认发动门槛为**家族等级 4、影响力 300、实际选中 60 名健康普通士兵**，并另留 1 人接应。影响力门槛是检查，不是直接扣除；玩家、英雄和伤兵不计入普通士兵门槛。
- 门槛与战斗参数可以在 MCM 中调整，新设置用于下一次发动。
- 街道与大厅采用实际兵员与幸存者选择，不凭空生成无限突击队。
- 清除门口守卫后才能继续攻入大厅；大厅队伍从街道幸存者中重新选择。
- 忠王派会对夺位作出反应，夺取大厅并不意味着所有家族都会立刻服从。

### 胜利之后仍有选择

- 胜利处置按玩家确认的选择推进，再进行政治结算、登基通知与战报。
- 取消处置界面不会擅自替玩家选择结果。
- 原王朝复位只在明确符合条件的叛军夺位胜利中处理，不把和平或妥协结局直接当成复位。
- 政变地点、推进与结果接入快报，报道依据确认事件，而不是预先编好的结局。

### 战斗体验调整

- 可配置街道与大厅人数上限、守卫人数、每波增援人数、增援间隔和同时存活波数。
- 修复大厅友军部署、进入大厅时的目标与选兵衔接，减少缺兵或重复部署问题。
- 改善增援出生距离，避免贴脸刷兵；离开街道阶段后不再继续生成街道增援。
- 调整高处远程守军部署，并修复已下令驻守的部队因敌军接近而错误出城的问题。

## 三、王国内战：派系有诉求，玩家有决定权

王国政治与内战系统继续扩展，不再只是后台生成一场叛乱。

- 加入政治面板及派系操作，可以查看派系与诉求，参与王国内部的政治博弈。
- 玩家可以**创建派系、解散派系、更改诉求，并在满足条件时手动起兵**。
- 更改诉求后，其他成员会重新评估是否继续参与，不保证所有人无条件跟随。
- 玩家派系不会自动替你招募成员或擅自起兵；手动起兵仍受军力比例和战后冷却等规则限制。
- 不满与王权支持会随真实事件变化，并按战役日平滑衰减；新统治家族的归属也与内战状态重新对齐。
- 修正不满来源、派系退出与战争结束的衔接。行政解散不会凭空新增长期战后冷却，也不会抹掉已有冷却。
- 原参与者会收到真实发生的退出、解散或创建事实，减少人物仍按旧派系关系回应的问题。
- 政策投票进一步考虑人物性格，让政治选择更符合人物立场。

## 四、新对话界面：人物、历史和资源放在一起

新的对话 UI 已整合进本体。

- 羊皮纸与卷轴风格的界面，配合人物头像和更完整的对话布局。
- 将对话历史与资源面板放入同一套界面，减少来回切换。
- 调整 AI 输入和离开操作，让常用交互更直接。
- 改善头像的眼部对齐、取景距离与填充，修复边缘杂色、背景露出和部分显示异常。
- 大地图会话也采用对应界面，并改善人物外观与当前角色状态的匹配。
- 修复相关界面与头像资源链路中的异常和崩溃风险。

## 五、AI 画卷：给会面与事件留下插画

AI 插画系统整合进本体。启用并配置对应服务后，可以为对话和事件生成画面，而不再只有文字。

### 更贴近当前人物与场景

- 结合人物年龄、实际装备、颜色、家族旗帜与场景信息组织画面参考。
- 改善群体活动、人数与环境参考，减少把野外画成城镇、把参考图拉成畸变全景等问题。
- 对话与快报有各自的生成流程，避免把同一张画机械地套到所有事件上。
- 首张手动生成后，可按配置进行对话联动重绘；并非每句对白都必定触发付费请求。

### 画廊与自定义

- 可编辑画风与相关生成配置，支持画卷标题、主题及画廊浏览。
- 画廊作品可以转成 RP 物品，用于后续角色扮演。
- 调整全屏画面、宽屏比例与输入区的关系，修复图片 DPI、颜色和缩放控制问题。
- 改善人物参考图准备与加载，减少未准备完成就开始生成的情况。

**注意：生图需要单独配置相应 API。生成速度、画质和费用取决于所选服务与模型；没有配置生图服务，不影响普通文字对话。**

## 六、快报与周报：消息更及时，记录更连贯

- 快报配图绑定实际事件与参与者参考，并支持在打开面板前预生成图片。
- 调整宽版排版、首字布局和档案入口，让正文与插图更好地配合。
- 增加政变进展与结果报道，并接入公开处决的确认结果。
- 修复近期消息选择、通知恢复与读档后的过期重试，减少旧消息顶替新消息、重复结算或重复处理。
- 修复周报展示与数据绑定，保留旧版阅读经验存储键。
- 城镇记忆按确认事件更新，刷新间隔调整为 **7 个战役日**，避免把未经确认的推测当作当地事实。

## 七、终端与 API 设置：配置更直观，回复处理更稳

- 增加图形化终端弹窗与 API 设置引导，完善设置保存及模型列表刷新。
- 主 API 提供流式开关，默认关闭；终端与 MCM 使用同一设置。
- 完整回复收到后再进行相关动作处理，避免将未完成的半句话当作一次成功交互。
- 修复 YJ 预设地址、查询参数和模型列表路径的兼容问题。
- 改善终端内搜索、周报绑定和战争统计下拉文字显示，并修复停战后的战争归档。

战争统计等功能在此前版本已经存在，本次主要是体验与可靠性改进，不作为全新玩法重复介绍。

## 八、对话、信使与记忆：减少串线，保留真实结果

本次还整理并修复了大量不容易在截图里看见、却直接影响游玩体验的底层问题。

- 改善自由对话、场景喊话和信使之间的规则、历史、动作与记忆衔接。
- 针对关窗、离场、取消和较晚返回的回复增加更严格的归属处理，减少旧会话影响新会话、错误对象收到动作和重复执行。
- 改善记忆压缩与编辑后的保存，修复单条编辑后未压缩内容丢失等问题。
- 修复部分决斗标签遗漏，以及释放、离开和会面收尾的处理。
- 战斗演讲进一步结合文化风格，并改善多行回复解析。
- 整理底层模块与扩展接缝，为后续功能联动提供更稳定的基础；这不代表所有外部子 MOD 已完成实机适配。

## 安装与升级提醒

1. **此次仍然只安装一个 `AnimusForge` 模块。** 发布包内同时包含 1.3 与 1.4 两套实现，由启动器适配层按游戏版本选择，不需要分别安装两个 AF。
2. 公开处决、政变、新对话界面与 AI 插画已整合在本次包中。不要同时启用会重复加载相同功能的旧独立副本。
3. Harmony、ButterLib、UIExtenderEx、MCM 等外部前置依赖仍需按项目要求安装，并与自己的游戏版本匹配。
4. 本包**不包含 ONNX 模型文件**。升级时保留已有模型；首次安装请按项目既有模型要求另外配置。
5. 升级前请备份存档、个人设置和自定义内容，不要为了更新手动清空这些数据。
6. 文字 API 与生图 API 是不同配置。启用生图前请确认服务、额度及相关开关。

本次已完成 1.3 / 1.4 双实现与 Bootstrap 编译、单模块打包及离线检查。不同补丁版本、旧档、真实 API 服务和具体场景的实机表现仍可能存在差异，不将编译或离线测试等同于全部游戏验收。

如果遇到问题，请尽量附上游戏版本、启用模块列表、复现步骤与相关日志；分享前删除 API 密钥等隐私信息。

感谢大家这段时间的等待。1.5 希望让卡拉迪亚中的行动不只发生在一个菜单里，而是能够被现场的人看见、被后来的人记住。
