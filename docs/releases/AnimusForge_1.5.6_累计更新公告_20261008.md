# AnimusForge 1.5.6 累计更新公告

**更新日期：2026年10月8日**

**更新范围：从上次正式的 1.5.5 公告发布后，累计至本次 1.5.6。期间已单独提供过的修复也包含在内。**

各位领主，这期主要更新快报、外交、场景生图与对话界面。快报可以写得更有现场感，外交回应和通知更加清楚；场景喊话与战斗增加双视角生图、连续后台生成和画廊入口，同时处理了一批会面、处决及读档问题。

## 一、周报／快报：独立设置，报道更生动

- MCM 将相关设置整理为 **“周报／快报”**，先选择主模式，再分别展开周报或快报设置；已有模式选择继续保留。
- 快报新增独立的 **“自动发布快报”** 开关和写作要求编辑入口。关闭自动发布后，不再发起新的快报生成和发布，必要的事件记录继续保留；已经发出的请求不保证立即取消。
- **快报允许合理补写动作、短对白和现场反应**，可以有勇气、机智、怒骂、嘲讽或狼狈场面，不再只是机械罗列“多少人打多少人”。保持原篇幅和重大结果，不凭空改变胜负、生死、俘虏、领土或外交关系。
- NPC 可以用“报上说”“听说”等方式转述快报轶闻；外交判断和事件记录仍依据真实素材，报刊描写不会真的改变伤病、关系或战争结果。
- 外交宣言，以及已有的政策、宴会、竞技等事件可以成为快报素材；同一宣言避免重复登记。宣言中的主张不等于事情已经执行。
- **降低结盟、解盟和外交宣言的选材优先级**，减少外交连续占据版面的倾向；其他关注加成继续生效，不保证每期题材比例固定。
- 快报配图改为从 **本期收录的大事件中抽选**，不再总是围绕第一条新闻。同一期的配图素材保持稳定，重新打开不会重新抽取。
- 优化开局摘要和每日资料维护，减少无效重试及重复处理。已有自定义快报写作要求和明确清空的内容保留，旧默认内容才随版本升级。

## 二、外交：回应更可靠，通知少打扰

- 修复正式回应可能被误当成普通讨论、已经同意的即时条约未正确落实的问题。
- 加强提案来源和条款核对：能识别部分省略前缀的有效提案编号，但仍需对应玩家已知、仍有效的原案。贸易接受时若改变期限，会要求另提新案，不再悄悄按旧期限执行。
- 口头和谈条件不完整时先说明缺少什么，避免先承诺已经执行；关闭 AI 外交时，支持的口头外交行动恢复使用原有执行方式。
- 修复外交回应在分析、回合清理和读档中的部分归属问题，减少旧回合任务干扰后续回应。
- **本国外交宣言保留右侧地图图标，其他国家使用左下角文字提示**。宣言继续保存在外交档案，并按传播范围进入 NPC 可知资料和快报素材。
- **删除“等待回应／剩余 X 日”的倒计时提醒**，包括令人困惑的“剩余 0 日”。回应入口和原有到期处理继续保留。

## 三、场景喊话与战斗：双视角资料、后台生图、画廊

- 面板增加手动生图入口，采集同一瞬间的两张现场参考，再交给视觉导演推演画面。
- **两张都是独立的平视机位**：第一张沿点击时玩家镜头的水平朝向观察人物区域，第二张从对侧回望。保留固定视野和原有取景距离，不跟随玩家镜头的俯仰或缩放。
- **参考图只提供现场资料，最终构图由导演决定**。导演可以重新选择机位、景别和画面安排，同时保持真实的人物关系、相对位置和事件边界。
- 喊话生图参考当前会话最近两轮完整多人对白；战斗生图以采集瞬间的动作和现场为依据，不推演未发生的伤亡或战果。
- 截图时会短暂隐藏界面、冻结现场并切换机位，完成后恢复。新增画面预热和近乎全黑参考图拦截，减少无效参考继续进入生图请求。
- **仅场景喊话和战斗允许连续后台生图**：上一张还在生成时，截图结束后即可再次点击，重新采集并创建独立任务。仍有任务容量限制；百科、普通对话和快报保留原有限制。
- 场景面板新增 **“画廊”** 按钮。采集完成后关闭面板，后台任务仍可继续保存作品，之后可以从画廊查看。
- 战役战斗中保留 **长按 T 框选、松开确认**：选到目标走原轮盘，没有目标且生图可用时才直接进入输入／生图面板。
- MCM 新增 **“自动屏蔽未框选人物”**，默认关闭；开启后减少未框选旁观者自动加入喊话，手动邀请、框选等明确选入方式仍有效。

## 四、画卷与生图配置

- 新增 **“重绘（基于本图）”**：直接使用当前显示的成图和本次修改要求，不重新采集现场，也不经过视觉导演；成功后独立保存新作品。
- 新增 **“叙事动漫”** 画风，并强化人物面部结构要求；新增 **“按 AF 装备保真”** 开关，默认开启。关闭后导演可设计衣甲和配饰，游戏中的实际装备不变。
- 改善定向换装、衣物破损、污渍和湿透等叙事的绘画要求，减少新旧衣装叠穿或强行恢复完好衣物；人物身份与事件事实仍需保留。
- 绘图显示效果默认改为 **全屏覆盖**，已保存的显示选择保留。加强尺寸与画幅要求，并改善等待状态、按钮文字可读性和相关面板入口。
- 修复生图模型选择与预设下拉框同步问题；导演最大输出预算默认 **25000 Tokens**，提供可选的提示词强制缩减设置。预算是上限，不要求模型写满。
- 增加或完善 **Player2、Grok 带图请求、Google 原生生图接口**支持，并修复部分接口因不支持顶层画幅字段而返回错误的问题。Google 原生支持针对生图链路，主对话与导演仍按各自接口配置使用。
- 生图设置与临时文件使用模组内目录；不自动读取或迁移旧 C 盘配置。提供显式的生图 API 测试按钮，点击可能产生服务费用。具体模型能力、画幅和生成质量仍取决于服务端。

## 五、对话与历史：滚动、输入和会面修复

- **降低对话滚轮速度**，减少轻滚一下就跳到最底的问题；历史记录中的 **“最新”** 会定位到真正的最新一页底部。
- 暂停喊话界面改用卷轴布局，并同步原版兜底界面；修复长输入的部分换行问题和历史链接跳转接线。
- 修复 AI 对话期间误触原版“继续”的问题，同时恢复正文滚动和等待时的 Esc 操作；从编辑器返回后恢复原版会话层的正常交互。
- 修复会面中确认开战后未正确接回原版战斗菜单，以及放行、投降期间部分过期回调和目标状态问题。
- 修复场景传话中明确停止指令可能被忽略的问题，缺少目标时给出更清楚的提示。

## 六、处决、城镇与其他调整

- 修复处决散场后残留交互预约导致退出卡住的一处原因；行刑期间暂停随行同伴和士兵的战斗 AI，减少其自行攻击犯人，结束或退出后恢复相应控制。
- 补齐城堡战后场景读档后缺失的上下文，改善后续战后菜单接续。
- 战后城镇对话增加言语反应和在场观察信息，人物进出、确认死亡等按各自观察记录；这些台词不会额外触发真实攻击或数值结算。
- MCM 政策设置新增 **“取消繁荣度耗粮”**，默认关闭，与粮仓容量设置独立；开启后适用于玩家和 NPC 的城市、城堡，关闭则保留原版耗粮规则。
- **新成年人物自动生成个性与背景默认关闭**，旧配置会进行一次关闭迁移，需要时可在 MCM 手动开启。
- 记忆导入增加文件格式检查，避免把个性文件等不相关内容误当作压缩记忆导入。此次不会自动恢复过去已经被覆盖的数据。

## 更新说明

- 安装包与启动器模块版本为 **1.5.6**，继续使用一个 AnimusForge 模块，内含 **Bannerlord 1.3.x／1.4.x** 两套实现。不要同时启用旧的拆分模块；ONNX 模型仍需单独安装，程序包不包含模型。
- 新增功能和修复已进行对应专项验证；两套实现、Bootstrap 和接缝通过构建检查。不同场景、旧档、第三方模组与真实 AI 服务的效果仍需要实机反馈。
- **坡地、草叶和近处人物造成的参考图遮挡，以及缺少阵营资料时的敌我误识别，尚未在本期完全解决。** 不将这两项列作已完成修复。
- 更新前退出游戏并保留存档备份；AI 功能继续使用玩家自己的服务配置。快报轶事的丰富度、重复程度和最终成图质量会因模型而异。
