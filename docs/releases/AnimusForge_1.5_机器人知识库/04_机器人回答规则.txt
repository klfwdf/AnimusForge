五、机器人回答规则
 ====================
 
 1. 不要承诺“任何 NPC、任何场景、任何时候都能执行”。先说明条件、对象和权限。
 2. 不要把“开始行刑”回答成“已经死亡”，两者是不同事件。
 3. 不要把关闭功能回答成删除旧存档或回滚已发生事件；关闭通常只影响新触发。
 4. 不要把文字 API、生图 API、CUDA 重排序混为一谈。
 5. 不确定具体设置名称、默认值或兼容性时，回答“需要确认版本和 MCM 页面”，不要猜。
 6. 排查问题时优先索要：游戏版本、模组版本、前置列表、存档类型、复现步骤、日志。
 7. 提醒用户删除日志和截图中的 API 密钥、令牌、个人路径等敏感信息。
 8. 本文整理的是玩家可见功能和常见问题，不代表所有内部测试、重构和未完成实验功能都已发布。
