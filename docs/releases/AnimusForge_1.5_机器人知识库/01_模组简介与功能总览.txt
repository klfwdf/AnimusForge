一、模组是什么
 ====================
 
 问：AnimusForge 是什么？
 答：AnimusForge 是《骑马与砍杀 2：霸主》的 LLM 互动模组。它把 NPC 对话、场景喊话、信使、政策、外交、处决、政变、快报和记忆系统连接起来，让 NPC 的回答和游戏中真实发生的事件相关。
 
 问：必须使用 AI API 吗？
 答：文字对话和大多数 LLM 功能需要配置文字 API。AI 画卷需要另外配置生图 API。不配置生图 API 不影响普通文字对话；不配置文字 API 时，相关 AI 对话和生成内容无法工作。
 
 问：支持哪些游戏版本？
 答：发布包包含 Bannerlord 1.3 和 1.4 两套实现，启动器会按游戏版本选择。不要把两套 AnimusForge DLL 同时放进游戏目录。

 二、主要功能
 ====================
 
 1. 公开处决
 - 从裁决、刑罚选择、刑场布置到现场执行的完整流程。
 - 支持开场、行刑中、结束后三阶段发言和最后陈述。
 - 可通过场景喊话或直接对话向本场刽子手下令。
 - 否定句、疑问句、条件句不会被当作立即执行命令；信使不能远程启动刑场。
 - 只有实际显示出来的发言才会写入记录；开始行刑不等于已经死亡。
 - 最近 100 场处决实录可保留在记录中。
 - 公开处决的入口和对象受游戏条件限制，不是对任意人物无条件开放。
 
 2. 宣权篡位
 - 符合条件时，玩家可在本国国王所在城镇发动行动。
 - 玩家带领真实部队进行街道战斗，再从幸存者中选择队伍攻入大厅。
 - 默认门槛：家族等级 4、影响力 300、60 名健康普通士兵，另留 1 人接应。
 - 影响力门槛默认只检查，不直接扣除；玩家、英雄和伤兵不计入普通士兵门槛。
 - 街道突击队、大厅突击队、守卫、护卫、守军波次和增援间隔都可在 MCM 调整。
 - 夺取大厅不等于所有家族立即服从；胜利后的处置和政治结算仍需玩家确认。
 - 关闭总开关只禁止新的发动，已经开始的战斗会安全收尾。
 
 3. 王国内战与派系
 - 可启用内战派系，让处决、封地落选、强推政策、强推战争或和约、领地遭劫等事件积累不满。
 - 可在政治面板查看派系和诉求。
 - 玩家可以创建派系、解散派系、更改诉求、满足条件后手动起兵。
 - 玩家派系不会自动替玩家招募成员或擅自起兵。
 - 可调整成派不满阈值、最后通牒间隔、最长内战周数、派系冷却、派系数量上限、同时内战和手动起兵条件。
 - 正式封臣玩家不会再被误判为没有参与资格；佣兵等原有限制仍然有效。
 
 4. 政策、投票与定居点
 - 政策可影响村庄生产、部队规模、招募、领主和封臣关系等。
 - 可启用“领主投票考虑利益、关系与性格”。
 - 投票可分别调整利益、关系、性格三项权重；默认权重为 1.00，范围为 0 到 3。
 - 政策档案可查看当前状态、效果、剩余时间、费用和反馈。
 - 可调整城市、城堡繁荣度上限，村庄户数上限，城市/城堡/村庄民兵上限，以及城市/城堡粮食容量。
 - 默认只开启粮仓容量调整，城市和城堡最终容量默认均为 1000；其他上限默认关闭。
 - 上限只限制总量；超过上限的数值不会被强行削减，正增长暂停，负增长仍会生效。
 - 使用第三方粮食模型时，部分容量和上限调整可能无法应用。
 
 5. 外交
 - NPC 的外交口头承诺可以记录、修订并写入记忆。
 - 多个外交事件可以同时推进，玩家回应会统一排程。
 - 外交文书公开后，相关人物会立即知晓。
 - 对话规则中有独立的外交识别入口。
 
 6. 对话界面与场景喊话
 - 可启用 AnimusForge 羊皮纸风格对话界面，带人物头像。
 - 场景喊话面板有三种风格：原样、卷轴式、右侧手札。
 - 卷轴式和右侧手札支持按住框选、松开展开轮盘，并进入持续的场景多人会话。
 - 可启用自动进入 AI 模式，并设置为仅 Hero 自动进入。
 - 原版对话和 AI 对话正文分开保存，不会互相覆盖。
 - 场景喊话支持召唤、带路、跟随等动作；动作必须满足对象、场景和规则条件。
 - NPC 回复生成时不能切换普通模式；生成期间点击“继续”不会打断当前回复。
 - 长的原版对话选项可以滚动，输入框和继续按钮的误触问题已修复。
 
 7. AI 画卷
 - 可为会面和事件生成插画，也可在画廊浏览并把作品转成 RP 物品。
 - 生图 API 与视觉导演 API 可以分开配置；导演 API 留空时可复用文字 API。
 - 支持模型、端点、密钥、分辨率、画质、画风、负面提示词、随机度、参考图、离屏环境渲染和本地缓存数量设置。
 - 可启用自动生图和 NPC 回复后的自动重绘；自动重绘需要先手动生成本次对话的首张图。
 - 重绘时可以输入本次指导意见。导演无法执行指导时会停止，不会悄悄按原样再画。
 - 野外会区分战前接触、行军相遇、战后处置俘虏和部队界面交谈，不再全部画成战前谈判。
 - 部队界面与 NPC 交谈时不做全景采集，以减少卡顿。
 - 生图速度、画质和费用取决于所选服务与模型。
 
 8. 快报、周报与信使
 - 可启用“即时快报”替代每周长周报。
 - 即时快报会收集约 1 天的大事合写成一篇，每期默认只调用 1 次 LLM，发出后冷却 3 天。
 - 世界快报、王国档案、国家筛选、日期排序、消息去重和重新打开快报均已支持。
 - 信使来信、回信和写信界面可使用国家信纸样式。
 - 快报依据确认发生的事件，不会把局部胜利写成击败整支围城军团。
 - 城镇记忆按确认事件更新，刷新间隔为 7 个战役日。
 
 9. 终端、API 与检索
 - U 键或大地图按钮可打开图形化终端，集中查看设置、战争统计、快报和周报。
 - 游戏内 API 引导提供 YJ、DeepSeek Flash、DeepSeek Pro 等预设，也支持自定义 API。
 - 主 API 支持流式传输开关，默认关闭。
 - 模型列表可实时拉取刷新；模型下拉会按模型名恢复选择，不再只按保存序号。
 - 可选 CUDA 重排序推理设备：默认 CPU，也可切换 NVIDIA CUDA；需要另装 CUDA 运行组件，修改后需要重启，失败时回退 CPU。
 - CUDA 重排序只影响检索排序，不等于让所有 LLM 推理使用 GPU。
