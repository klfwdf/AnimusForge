三、安装与设置
 ====================
 
 问：应该安装几个 AnimusForge 模块？
 答：只安装一个 AnimusForge 模块。发布包内部包含 1.3 和 1.4 两套实现，由 Bootstrap 按游戏版本选择。不要同时安装旧的 AnimusForge_Illustrator、AnimusForge_DialogueUI、AnimusForge_Coup 独立副本。
 
 问：需要哪些前置？
 答：通常需要与当前 Bannerlord 版本匹配的 Harmony、ButterLib、UIExtenderEx、MCM 等前置。具体以发布包说明和当前游戏版本为准。
 
 问：升级前要做什么？
 答：备份存档、MCM 设置、世界书和自定义内容；保留已有 ONNX 模型文件。升级后先确认模块只加载一次，再测试 API、场景喊话、快报和存档读取。
 
 问：文字 API 和生图 API 是一回事吗？
 答：不是。文字 API 用于 NPC 对话、规则判断、快报等；生图 API 用于插画。两者需要分别配置。
 
 问：怎么打开终端？
 答：默认使用 U 键，也可以通过大地图按钮进入。战争统计、快报和周报都集中在终端中。
 
 问：为什么 AI 画卷不生成？
 答：依次检查：是否启用生图总开关；端点、密钥和模型是否正确；服务是否支持对应接口；是否配置了视觉导演 API；是否仍在生成或被缓存/退出战役取消。没有生图配置时，普通文字对话仍可使用。
 
 问：为什么 CUDA 没有生效？
 答：CUDA 重排序只支持 NVIDIA 显卡，需要额外安装可选 CUDA 运行组件，并在修改后重启。组件缺失或初始化失败时会回退到 CPU。它只影响重排序，不负责普通 LLM 推理。
