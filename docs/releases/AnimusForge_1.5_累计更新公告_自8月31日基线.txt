AnimusForge 1.5 累计更新公告

更新日期：2026 年 10 月 5 日
对比基线：2026 年 8 月 31 日的版本（模块版本 v1.3.7.2）→ 本次 v1.5.0
各位领主，好久不见。

和 8 月底的版本相比，这次不是修修补补。公开处决、宣权篡位、全新的对话界面和 AI 画卷都已整合进本体，王国内战有了玩家可用的操作，快报、外交、政策和 AI 对话也接得更紧。MCM 设置项从 253 项增加到 317 项，没有删除任何旧设置。

下面按玩家能感受到的内容整理。标注“最新”的条目，是 10 月 3 日之后才加入的。

---

一、本次重点

- 公开处决：判决、刑罚选择、刑场、最后陈述、向刽子手下令的完整流程。
- 宣权篡位：带真实部队攻入城镇街道和大厅，争夺王位。
- 王国内战：派系有诉求、有阈值、有冷却，玩家可以创建派系、更改诉求、手动起兵。
- 全新对话界面：羊皮纸风格，场景喊话可选“原样 / 卷轴式 / 右侧手札”三种面板风格。
- AI 画卷：为会面和事件生成插画，自带独立的生图与导演 API 设置。
- 即时快报：可以取代每周长周报，大事发生后合写成一篇。
- 图形化终端与 API 引导：设置、战争统计、快报和周报集中在终端里。
- 政策、投票与外交：领主投票会考虑利益、关系与性格；外交口头承诺可记录、可修订（最新）。

---

二、公开处决

公开处决现在是完整玩法，不再只是处决后弹出一段文字。界面新增了处决裁决面板、刑场布置面板和现场发言气泡。

- 可按系统允许的对象与条件进行裁决、选择刑罚，并进入实际刑场。并非对任意人物无条件开放。
- 提供多种刑罚方式，也可以自定义刑场布置和预设。不同选择会影响贵族与平民的认可、安全度、忠诚度等结果。
- 轮刑已从新的刑罚选择列表中隐藏。旧记录和旧预设中的相关内容仍保留。
- 新增处决相关的物品数据，随模块一同加载。

人物会在现场发言
- 发言分开场、行刑中、结束后三个阶段，并结合人物、案件和已有记忆。
- 新增最后陈述环节。你可以听完，也可以提前下令。
- 可以通过场景喊话或直接对话，向本场刽子手下达行刑命令。否定句、疑问句、条件句不会被当作立即执行的命令。信使不能远程启动刑场。
- 对话规则里新增了“公开处决启动”这一项，刽子手的命令由它识别。
- （最新）确认行刑的命令发出后，不再需要多点一次“离开”才能开始。

只有发生过的事才会留下记录
- 现场真正显示出来的发言才写入记录，没说出口的内容不会事后补造。已死亡的人物不会继续发言。
- 现场记录会进入符合条件的听众的记忆，并保留最近 100 场处决实录。
- 快报和周报依据确认结果传播：开始行刑不等于已经死亡，不会仅凭一句命令就提前写成死亡新闻。

三、宣权篡位：亲自带兵争夺王位

符合条件时，你可以在本国国王所在城镇发动行动，带领实际部队在街道战斗，再从幸存者中选择队伍攻入大厅。

MCM 里新增“启用宣权篡位”总开关，关闭只禁止新发起，已有战斗会安全收尾。默认参数：

| 项目 | 默认值 |
|---|---|
| 最低家族等级 | 4（0 表示不限制） |
| 最低影响力 | 300（只检查，不扣除） |
| 最低突击队人数 | 60 名健康普通士兵，另留 1 人接应 |
| 街道突击队人数上限 | 60（不含玩家） |
| 大厅突击队人数上限 | 20（不含玩家，只能从街道幸存者中选） |
| 门口守卫人数上限 | 10 |
| 大厅护卫人数上限 | 20（不含国王） |
| 守军每波人数 | 30 |
| 守军增援间隔 | 30 秒 |
| 同时存活的守军波数上限 | 4 |

- 玩家、英雄和伤兵不计入士兵门槛。所有参数只影响下一次发动。
- 清除门口守卫后才能攻入大厅。守军从真实守军中分配，不足时按实际人数。
- 忠王派会对夺位作出反应。夺取大厅不意味着所有家族立刻服从。
- 胜利后的处置按你的确认推进，再进行政治结算、登基通知和战报。取消处置界面不会替你选结果。
- 原王朝复位只在明确符合条件的叛军夺位胜利中处理。
- 政变地点、进展和结果会出现在快报里，依据的是确认发生的事件。
- 增援不再贴脸刷兵，离开街道阶段后不再继续生成街道增援；已下令驻守的部队不会因敌军接近而错误出城。

四、王国内战：派系有诉求，你有决定权

新增“启用内战派系”总开关。开启后，王国内部会因处决、封地落选、强推政策、强推战争或和约、领地遭劫等事件积累不满，不满达到阈值后由家族牵头成立反对派。

- 新增政治面板，可查看派系与诉求。
- 玩家可以创建派系、解散派系、更改诉求，并在满足条件时手动起兵。更改诉求后，其他成员会重新评估是否继续参与，不保证所有人跟随。
- 玩家派系不会自动替你招募成员或擅自起兵。
- 不满与王权支持会随真实事件变化，并按战役日平滑衰减。
- 原参与者会收到真实发生的退出、解散、创建事实，减少人物仍按旧派系关系回应的问题。

MCM 里可调的内战参数：

- 玩家为国王时也形成派系（让你的王国也会出现反对派并向你递交最后通牒）。
- 结果随机度：1 为按概率掷骰，0 为按期望值直接决定。
- 成派不满阈值、最后通牒间隔（周）、内战最长周数（默认 12）、派系冷却周数（默认 8）。
- 同时存在的派系上限（1 到 4）；允许多个派系同时内战（默认关闭，同一时间只允许一个派系起兵）。
- 玩家手动起兵所需的军力占比（%）、起兵所需的最少被拒次数。

修复：已成为正式封臣的玩家不再被误判为没有参与资格（佣兵等限制仍保留）。强推决议的不满只在统治者实际逆多数作出决定并生效后计入一次。这次没有统一下调叛乱概率，也没有清空已有不满或战后冷却。

五、政策、投票与定居点

领主投票
新增“领主投票考虑利益、关系与性格”开关。开启后，王国议程中的自定义政策（玩家与 NPC 统治者提出的都适用），领主除了原版政治立场，还会考虑：

- 政策对自己封地、家族的实际利弊；
- 自己与提案人的关系；
- 政策手段与自己性格（仁慈、荣誉、慷慨、勇气、审慎）是否匹配。

三项权重可分别在 MCM 调整（投票利益权重、投票关系权重、投票性格权重，范围 0 到 3，默认 1.00）。已谈妥的拉票承诺优先兑现。旧政策没有性格评议数据时保持原评分，可重新评议生成。

政策档案
- 整合玩家王国、地方、附庸和 NPC 政策，显示当前状态、实际效果、剩余时间、费用和反馈。
- 已废除、到期或失去适用对象的政策，在没有生效效果和未完成事务时可删除历史记录。删除不会撤销过去的效果，也不会抹掉人物的记忆。
- 新增两项 AI 评议参考设置：本国最新政策、世界相关政策的参考条数，设为 0 可关闭。这不限制王国能拥有多少政策。

定居点上限与粮仓容量
新增 MCM → 政策相关数值上限调整 → 调整上限与容量，并有专门的调整面板。可分别设置：

- 城市、城堡的繁荣度上限，村庄户数上限；
- 城市、城堡、村庄的民兵总人数上限；
- 城市和城堡的粮食库存容量。

默认只开启粮仓容量，城市和城堡最终容量均为 1000，其余六项默认关闭。上限限制总量，不是每日增长额度。已超过新上限的数值不会被强行削减，正增长暂停，负增长仍然生效。使用第三方粮食模型时，部分调整可能无法应用。

六、外交（最新）

- NPC 在对话中口头作出的外交承诺会被记录，可以修订，并进入记忆。
- 多个外交事件可以同时推进，玩家的回应统一排程。
- 外交文书公开后，相关人物会立刻知晓。
- 对话规则里新增了“外交”这一项，用来识别和处理外交相关的口头内容。

---

七、对话界面与场景喊话

- 新增“启用 AnimusForge 对话界面”开关。羊皮纸风格的对话界面，带人物头像，大地图会话也使用对应界面。
- 场景喊话新增“场景喊话面板风格”选项：原样保持原有的 T/Y 喊话流程与输入框；卷轴式是底部卷轴输入加右侧受众挂札；右侧手札是右侧竖版对谈手札。后两种会把 T/Y 合并为“按住框选、松开展开轮盘”，并进入持续的场景多人会话。
- 对话历史和资源面板放进同一套界面。可选择是否在对话历史里显示删除按钮。
- 新增“自动进入 AI 模式”，并可选“仅 Hero 自动进入”。普通对话与 AI 对话的正文分别保存，切换模式时不会互相覆盖。
- 修复了点击输入框空白区域无法“继续”、按开场快捷键时按键被带进输入框的问题。长的原版对话选项现在可以滚动。
- 场景喊话在按键、蓄力和输入期间不再累积凝视，减少误触“盯着 NPC 看”。
- NPC 回复里已经做出的可见身体动作会被识别为场景动作（新增 SCENE_ACT，只判断动作是否发生，不要求 NPC 同意）。
- （最新）NPC 回复正在生成时，不能切换到普通对话模式。
- （最新）NPC 主动开口、正文正在生成时，点击“继续”不再打断这一轮。
- （最新）对话面板的尺寸与滚动条已调整，原版告别对话的收尾更顺畅。
- （最新）原版领主会面被接管后的退出与返回更稳，相关抑制只作用于当次遭遇。
- （最新）场景召唤、带路、跟随等动作在重构后已重新接通。

八、AI 画卷

启用并配置生图服务后，可以为会面和事件生成插画。MCM 新增了完整的生图设置，包括：

- 生图开启：全部生图入口的总开关。
- 生图 API：端点地址（可选“使用完整调用 URL”）、密钥、模型名称与下拉、拉取模型列表、分辨率、画质预设、画风、自定义画风提示词、负面提示词、随机度。有参考图时默认走 /images/edits。
- 视觉导演 API：可独立配置端点、密钥和模型，留空则复用正文 API。可在“自定义导演提示词”里添加自己的构图要求，保存后用于下一次生成。
- 自动生图、NPC 回复后自动重绘场景插画（需先手动生成本次对话的首张图）、绘图显示效果、本地缓存最大保留张数。
- 向生图模型附带参考图（垫图）、启用场景离屏渲染（环境全景）、生成完成后自动清理临时文件。

使用上：

- 结合人物年龄、实际装备与颜色、家族旗帜、场景信息和在场人数组织画面。对话与快报各有自己的生成流程。
- 支持画风预设、画卷标题与主题、画廊浏览，画廊作品可转成 RP 物品。
- 关闭面板不会中断已经开始的生成，完成后提示“绘制完成，已更新到画廊”。换档或退出战役会取消旧任务。
- （最新）重绘时可以写下本次的指导意见。如果导演无法执行，会停止重绘，而不是悄悄按原样再画一张。
- （最新）会面入口会被区分：战前阵前接触、行军途中相遇、战后处置俘虏、在部队界面与己方成员或俘虏交谈。野外对话不再一律画成战前谈判。
- （最新）在部队界面与 NPC 交谈时，不再做全景采集，减少卡顿。

生图需要单独配置服务，速度、画质和费用取决于所选服务与模型。不配置生图，不影响普通文字对话。

九、快报、周报与信使

- 新增“周报模式：即时快报”开关。开启后用即时快报取代每周长周报：大事发生后收集 1 天，把期间几件大事合写成一篇并附几条小消息，每期只调用 1 次 LLM，发出后冷却 3 天。内容偏向玩家本人、本国与邻国，启用生图时自动配图。关闭则使用旧周报。
- 新增世界快报面板。配图绑定实际事件与参与者，可在打开面板前预生成。
- 新增“信纸样式”选项，信使的来信、回信和写信界面统一使用所选的国家信纸预设。
- 修正出城伏击、出城作战的判定，报道依据实际参战部队和结果，不再把一次局部胜利写成击败整个围城军团。
- 王国档案可查看相关的最新快报，支持日期排序、国家筛选和消息去重。
- （最新）档案里零散的事实会归入各国档案，档案卡片重新设计，快报档案可以重新打开，各国视图互不混杂。
- 修复了旧消息顶替新消息、读档后重复结算的问题。城镇记忆只按确认发生的事件更新，刷新间隔为 7 个战役日。

十、终端、API 设置与检索

- 新增图形化终端弹窗，整合设置、战争统计、快报与周报。战争统计是终端里的独立页签，可用 U 键或大地图按钮打开。
- 新增游戏内的 API 引导向导，内置 YJ、DeepSeek Flash、DeepSeek Pro 预设，也支持自定义多个 API。
- 四类 API 的模型列表随拉取实时刷新。主 API 新增“开启流式传输”，默认关闭。
- 修复了 YJ 预设地址、查询参数和模型列表路径的兼容问题。
- （最新）新增可选的“重排序推理设备”：默认 CPU，也可选 GPU（CUDA）。仅支持 NVIDIA 显卡，需要另外安装可选的 CUDA 运行组件，修改后需要重启，在独立进程中运行，无法使用时回退到 CPU。
- （最新）MCM 中的模型下拉偶尔被换成另一个模型的问题已改进：现在按模型名记住并恢复选择，不再只依赖保存的序号。

---

十一、稳定性

- 自由对话、场景喊话和信使的规则、历史、动作与记忆衔接更稳。关窗、离场、取消或较晚返回的回复，不会再影响新的会话或让错误的对象收到动作。
- 完整回复收到后再处理动作，避免把未完成的半句话当成一次成功交互。
- 记忆压缩与编辑后的保存更可靠，修复了单条编辑后未压缩内容丢失的问题。
- 修复了部分决斗标签遗漏，以及释放、离开和会面收尾的问题。
- （最新）叛乱成功后的“自动叛乱执行完成”等提示不再被当作报错，不会弹出“是否分析报错”。
- （最新）野外拦截领主不再被过期的劫掠或战斗状态误拦。
- （最新）NPC 在市集交易界面赠送礼物时，不再随机生成多余物品。

升级与反馈

1. 仍然只安装一个 AnimusForge 模块。 发布包内含 1.3 与 1.4 两套实现，由启动器按游戏版本选择。
2. 公开处决、政变、新对话界面与 AI 画卷都已整合在本体里。请不要同时启用旧的独立副本：AnimusForge_Illustrator、AnimusForge_DialogueUI、AnimusForge_Coup，否则可能重复加载。
3. Harmony、ButterLib、UIExtenderEx、MCM 等前置依赖请按游戏版本安装。
4. 本包不含 ONNX 模型文件，升级时请保留已有模型。
5. 升级前请备份存档、个人设置、世界书和自定义内容。
6. 文字 API 与生图 API 是两套配置。

关于验证：本次内容已通过 1.3 / 1.4 双实现编译。标注“最新”的改动，尤其是外交承诺与并行外交、CUDA 重排序、模型下拉修复、“继续”按钮拦截和叛乱提示修复，还没有完整的实机验收。不同补丁版本、旧档和真实 API 服务下的表现可能有差异。

反馈问题时请附上游戏版本、启用的模块列表、复现步骤和相关日志。分享前请删除 API 密钥等隐私信息。
