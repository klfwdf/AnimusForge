# AnimusForge 1.6.2 累计更新公告

日期：2026年10月17日

本期以 **10月15日的 1.6.1 更新公告**为基线，汇总此后陆续发布的修复与调整。本次重点是场景交流、人物记忆、城镇近期情况，以及中英文内容包的使用体验。

## 场景交流：打断更利落，多人喊话接得上

- 修复点击“打断”后，回复仍在继续或会话卡在等待状态的问题。打断会停止当前回复流程，已经显示的气泡内容保留。
- 框选多名 NPC 喊话时，现在会按群体交流识别，不再要求玩家一定说出“大家”“所有人”等特定称呼。修复部分情况下首位 NPC 回复后，接力过早停止的问题。
- 群体接力会优先考虑尚未回答的在场对象，避免为了接力反复点回同一个人；仍受会话结束、目标是否在场和轮次上限约束，并非每次都让所有人依次发言。
- 场景对话右侧手札面板加入展开与收起动画。
- 流式对话加入逐字显示，按每秒约 20 个字符呈现，完善文字展示与等待状态的衔接。

## 人物设定：手动重生参考压缩记忆

- 手动重新生成人物个性、背景与扩展人设时，在原有世界书和人物事实之外，可以参考该人物已有的压缩记忆。
- 最终采用收紧后的规则：只取近 **10 个游戏日内最新一份压缩记忆**，最多携带约 **800 字符**；没有符合条件的记忆就不附加。
- 不再把刚发生的巡逻、移动、拦截等近期行动流水直接塞进重生请求，减少眼前一次遭遇把人物整段背景带偏的情况。记忆用于提供经历参考，不能替代人物的已知事实。
- 完善中英文历史中的玩家、NPC 与旁听发言识别，减少玩家的话被当成 NPC 的话，以及同一轮内容重复进入上下文的问题。

## 城镇新增近七日情况

- 城镇记忆可展示近七日已记录的本地事件，以及村民队伍、商队的到访次数。
- 已确认的攻占、劫掠、战后处置等事件会保留实际发生者与日期；已接入的附属村庄事件也会归入对应城镇。
- 近期情况保留独立标题，正文精简为事件和已记录的到访计数，去掉反复出现的空记录说明。
- 调整统治者记忆的叙述要求，使其更充分体现任期中的已知事件。近期事实与统治者历史分别保留。
- 到访次数从实际记录中累计，旧存档没有留下的历史次数不会凭空补齐。

## 中英文、世界书与外交

- 完善世界书导入时的中英文内置人物名称匹配，减少同一个人物仅因名称语言不同而无法对应的问题。
- 补齐场景旁白、手动触发标记、部分经济动作事实及外交显示、日期和历史固定说明的双语处理。
- 修复部分解析只认识中文的问题，包括家族入国上下文、外交意图与文书事实、部分政策目标排序和场景配置的兼容读取。英文输入继续遵守与中文相同的游戏条件。
- 完善对话后处理对已发生事实的读取，保留事实的当下与过往范围，减少漏掉执行结果的问题。
- CN/EN 包决定固定提示词和内置世界书的语言，界面跟随游戏语言。玩家自定义要求、已生成正文和旧历史保留原文，切换 EN 包不会自动翻译存档，也不会强制 AI 只能回复英文。

## 导入、设置与兼容修复

- 世界书导入失败后提供明确的“重试 / 跳过”选择，避免失败后立即反复弹出目录选择。跳过仍需确认，也不代表本次导入已成功。
- 存档内重载数据库时，跳过没有匹配资料的动态王国，避免这一项挡住其余资料重载。
- MCM 恢复独立的“AnimusForge终端设置”页，与终端共用设置；整理 API 分类和生图设置位置。
- 正式移除隐藏的独立导演 API、导演模型和生图“完整路径”开关，旧配置不再参与请求。导演构图步骤保留，统一使用主 API；生图接口仍使用自己的设置并自动识别标准端点。
- 修复部分模型下拉框选中项失效导致的终端异常，以及多次开关 MCM 后的界面卡顿问题。
- 针对权游模组中部分招募人物缺少原始角色模板的情况，补充百科名称读取保护，修复对应崩溃路径。
- 修复 NPC 已答应投降、动作已经排队，却一直没有执行的问题。
- 周报插画不再仅因构图中出现否定描述、引用事件内容或不同的段落布局，就退回备用构图；仍保留游戏事实和画面还原要求。

## 下载与安装

- 提供 **CN、EN 两份完整内容包**，按需要选择其中一份安装。每份都只有一个 `AnimusForge` 模块，并包含 Bannerlord 1.3.x / 1.4.x 两种实现。
- **ONNX 模型仍为独立下载**，本次更新包不包含模型；已有模型继续保留在模组的 `ONNX` 文件夹。
- 更新前请备份存档和自定义提示词、世界书等资料。保留的自定义语言要求仍然有效，可在遇到回复语言与预期不符时检查。
- 发布前已完成双版本构建、相关离线回归与 CN/EN 完整包校验。真实模型输出、长期旧档及第三方模组组合仍需游戏内验证。
