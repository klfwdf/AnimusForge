# AnimusForge 1.6.0 累计更新公告

日期：2026年10月13日

本公告汇总 **1.5.7 正式版至 1.6.0** 的累计更新，包含期间 1.5.8 与单独修复的内容。各位领主，这期主要完善中英双语内容包、重新整理终端设置，并修复模型列表拉取、场景接力、记忆清除与生图协议问题。

## 中英双语内容包

- 提供 CN、EN 两种内容包，补齐对话、信使、记忆、外交、政策、周报、快报、场景动作、插画与世界书的固定文本。
- 两种包都保留中英文界面。界面随游戏语言切换，固定提示词与世界书随安装的内容包选择；例如 EN 包也可以在中文界面下使用。
- 移除按内容包强制 AI 使用中文或英文回复的附加规则。实际回复语言由上下文和玩家自定义写作要求决定，生成标题与主题也不会因为包含另一种语言而被清空。
- 修复世界书中的异常换行与瓦兰迪亚历史末尾重复数字污染。

## 终端设置与对话面板

- 将同类设置集中到同一页、同一折叠条目：武装政变合并；周报与快报集中在“外交与国家”；AI 外交整理为“设置”和“提示词”两个条目；自然语言动作与战场喊话合并。
- 生图 API 集中到“AI 核心”；隐藏导演 API 设置入口，导演规则编辑器移到提示词页。隐藏安全与诊断入口及环境 AI 用量显示选项。
- 移除终端子项前面的数字编号，调整滚动与分页，避免展开过多条目后底部设置找不到。
- 后续可改选项以终端为主要入口。场景与原生对话面板的“手动触发标签”仅在开启开发者数据管理时显示并允许执行。
- 场景喊话历史的正文字号同步普通对话历史字号设置。

## 对话、场景与记忆

- 修复场景喊话接力中部分话题资格与结束信号问题，减少多人交流中途不再接话的情况。接力仍会根据对象、话题和模型判断结束。
- 自动盯视 NPC 触发交流默认关闭，减少站在人物面前时意外开启交流。
- 终端新增正向 NPC 关系/私人关系的最小增量设置。
- 清除聊天历史时同步清理缓存记录，减少清空后仍接续被删除剧情的情况；不会自动恢复此前已经丢失的记录。
- NPC 个性资料扩展到性格特征、动机、价值观、恐惧和说话风格，并接入场景无名人物的个性生成。修复编辑个性时场景画面停止刷新及部分后台线程访问问题。
- 会面护卫复用已分配的原版士兵，改善会面中的护卫与队伍衔接。

## 模型列表、插画与语音

- 修复模型列表拉取后的界面刷新、选中模型保存与缓存重读，改善点击无反应、卡顿或列表被清空的问题。拉取是否成功仍取决于所配置服务是否支持模型目录接口。
- 修复 EN 插画导演输出合法英文协议却被判定不完整的问题；保留必要场景段落、事实与构图检查。
- 压缩重复人物/参考图/装备提示词，共享通用视觉规则，保留每个人物自身的身份、装备与参考图差异；新闻插画控制为最多两名主要参与人物。
- 增加火山引擎 V3 HTTP 与 Agent Plan HTTP TTS 的兼容支持，改善测试失败信息的显示；原有播放流程保留。

## 外交、政策与新闻

- 玩家外交文书的生成尊重设置的篇幅，不再仅因完整文本偏长而拒绝；统治者回信可复用文书撰写入口。
- 口头外交宣言接入 AI 撰写，约定的条约继续走实际机制校验与执行；修复新和平提案的来源检查。
- 政策效果检索更关注原始措施、目标与明确数值，减少从不相关内容推导效果的情况。
- 快报写作要求强化现场细节、短对白与旁观反应，减少像数据库逐项复述的报道；依然以确认事实为边界，不凭空改变胜负、生死、领土或外交结果。
- 快报发布开关独立生效；战事报道继续限制兵力/伤亡数字对账，并修复部分日期、预览与内嵌插画表现。

## 大地图命令与数据目录

- NPC 队伍可通过既有命令链路处理已知强盗藏身点，执行仍检查目标、队伍与战斗条件。
- 手动标签接入既有大地图与场景动作入口，保留对象、权限与执行结果检查。
- 模组运行文件集中在当前安装的 AnimusForge 目录。旧 AppData/Documents 中的 AF 文件不再自动读取或迁移；已有玩家提示词、配置和导出数据继续保留。
- 部署工具移除自动 Recovery 备份与回滚机制，保留安装路径和玩家目录保护。

## 安装与验证说明

- 每份包只有一个 `AnimusForge` 模块，内含 Bannerlord 1.3.x / 1.4.x 实现，由 Bootstrap 选择对应版本。
- CN/EN 是内容版本选择。更新前退出游戏，选一份包安装；ONNX 模型仍按独立模型包安装。
- 本期完成双版本构建、相关离线回放和资源/打包门禁。真实游戏、外部模型服务、所有旧存档与第三方模组组合尚未全部验证；AI 文风、语言选择与插画效果仍受模型和输入影响。
