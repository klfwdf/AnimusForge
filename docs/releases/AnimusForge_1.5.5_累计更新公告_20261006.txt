AnimusForge 1.5.5 累计更新公告

更新日期：2026年10月6日

更新范围：上次发布的 1.5.4 之后，累计到本次 1.5.5 的新增内容与修复。

各位领主，本次更新重点完善公开处决、对话界面和内政体验：行刑时减少场景冲突误触，欢呼结束后民众可以逐步散场；对话正文大小可以自己调整；NPC 对亲属生死状态的了解、场景插画对当前对话和重绘要求的理解也有所改善。同时调整了内战节奏，并合入一批战后收编和场景移动修复。

一、公开处决：行刑期间隔离，结束后恢复正常互动

- 行刑期间隔离普通场景冲突，修复玩家行刑挥刀、投石等动作可能误触挑衅或城镇冲突的问题。
- 仪式、欢呼和收尾完成后，恢复正常场景互动。此后玩家主动攻击其他人，仍可按原有规则触发冲突。
- 欢呼结束后，围观民众会分批散开，不再一直站在刑场周围。散场会优先选择远离刑场的可用位置，并检查路线是否穿过刑场；没有合适路线时不会强行派人穿场。
- 散场期间如果发生新的警戒或战斗，会交由对应行为处理，避免继续强制散场干扰战斗。
- 修复处决结束后主动攻击导致卡死的一处明确原因：临时生成的人物在受惊逃跑、寻找门口时缺少城镇身份信息，可能触发异常。本次补齐了身份登记、后续行为初始化与离场清理。

散场避让用于和平状态下的离场；进入战斗后的追击、逃跑仍由战斗行为决定。

二、对话界面：新增正文字号，默认使用新 UI

在 MCM → AnimusForge - 对话界面 → 1. 界面 中：

- 新增 “正文字号”，范围 14–36，默认 24。影响新 UI 的对话正文、选项、历史和输入文字；按钮、人物名及原版界面字号不变。重新打开对应界面后生效。
- 原来的界面开关改为 “原版 / 新 UI” 选项，默认选择新 UI。喜欢原版布局的玩家可以直接切回。
- 场景喊话默认采用 卷轴式。已经明确保存过其他喊话风格的玩家，会保留原来的选择。
- 旧配置如果没有新的界面选项记录，会采用新 UI 默认值；此前关闭过旧开关的玩家，如需继续用原版，请在新选项中重新选择。

同时修复原版对话中“给予 / 展示”对目标的误判，减少人物仍在交谈却提示“已经离场或失效”的情况。真正结束会话或切换目标后，旧操作仍会被拒绝。

三、NPC 与画卷：更贴近当前人物状态和这次对话

NPC 亲属状态

- 自由对话、场景喊话和信使交流都会补充当前亲属、家族成员的在世或已故状态，包括可以查到的已故前配偶，减少 NPC 仍把已故亲人当作在世人物的问题。
- 当前状态优先于旧背景描述，但不会凭空推断死因，也不会自动重写已有的人设或历史记录。

场景插画与重绘

- 场景插画改为参考 当前会话最近两轮对话，保留同一轮中的分段回复；自动重绘也会衔接上一轮内容，减少动作上下文缺失或混入上次会面的内容。
- 本次明确填写的重绘要求优先。例如要求“加一把剑”，会优先协调这条要求与原图、默认构图限制、长期偏好之间的冲突；没有要求修改的部分仍尽量保留。
- 这项调整适用于人物、会话场景以及周报 / 快报重绘，只影响画面，不会改变游戏中的真实装备或人物事实。具体成图效果仍取决于所用模型。

四、内战与内政：放缓矛盾累积，减少同时起兵

- MCM 新增 “世界叛乱上限”，默认 3 场，可在 1–20 之间调整。达到上限时，新的 NPC 内战会等待名额释放；降低上限不会强制结束已有战争。
- 玩家手动发起或明确批准的起兵不受这项上限阻止，但会占用名额，其他起兵条件仍需满足。已登记的政变战争也计入数量，政变发起本身不受此限制；原版城镇叛乱不计入。
- 事件和行动带来的 新增怨恨值减半，放缓派系矛盾累积；已经存下来的怨恨值不会直接减半。
- 新递交给玩家国王的最后通牒，答复期限由 2 周延长至 4 周。
- 修复内政面板“立即裁决”和底部操作按钮上多出一块矩形底色的问题，恢复原版按钮边缘效果。
- 调整终端“王国近况”的标题和条目居中显示，并移除重复的“查看王国公告”入口；政策撰写、地方政策和“王国近况”入口保留。

五、战后处置与场景移动

- 城堡收编会提前检查主队空余人数，并扣除此前已经承诺收编的名额。超出容量的俘虏保留为未分配状态，可以另行处置。
- 收编相关的信任变化按实际成功结果处理；士兵对收编产生的士气惩罚按 实际入队人数 折算，没有人成功入队时，不收取这部分惩罚。其他处置造成的不满仍按原规则结算。
- 已经安抚过士兵后，只有新出现的更强不满才会重新要求安抚。
- 调整战后处置和带兵入城相关 NPC 的移动、卡住恢复逻辑：优先使用原版寻路，持续卡住时先重试，再进行受限制的小范围脱困，减少重复下令和不合理的远距离位移。
- 修复重复下达城镇殖民操作时可能重启已结束流程或覆盖原目标的问题。

六、海上交谈退出

- 修复玩家主动找海上友军交谈后，结束对话却继续弹出攻击菜单的问题。
- 对方主动拦截、真实战斗以及投降等情况，仍按原有遭遇规则处理。
