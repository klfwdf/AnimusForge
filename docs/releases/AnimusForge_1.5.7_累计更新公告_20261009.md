# AnimusForge 1.5.7 累计更新公告

日期：2026年10月9日

本公告汇总上次正式 1.5.6 发布以来累计至 1.5.7 的更新，期间单独提供过的修复也包含在内。

各位领主，这期重点处理场景喊话接力、重新进入对话后的记忆衔接、弹窗无法操作和外交通知问题，同时把场景生图改为自由取景，并完善画廊与配置保存。

## 一、场景喊话与界面

- 修复场景喊话轮盘、给予和展示菜单的部分入口失效。
- 调整多人接力：群体提问不再让一位 NPC 代替所有人回答；已经发言的人仍可接话；后续发言会携带当前话题和前人对白，减少重复回答原问题、聊一两轮便结束的情况。接力仍可因话题结束、无人愿意回应或模型判断提前停止，不保证每次接满八轮。
- 修复未开启语音或语音失败时正文显示延迟，减少下一轮一直等不到文字的情况。
- 受众卷轴贴近屏幕顶部，增加展开与收起动画。

## 二、对话、记忆与输入

- 修复重新进入自由对话后，已有未压缩历史没有完整带入请求的一处问题，改善 NPC 首句忘记此前交谈、读档后才恢复的情况。
- 新会话会根据已有记录提示距上次交流经过的游戏时间；资料不足时不编造间隔。
- 编辑、删除单条自由对话记录时保留同日其他历史；带路、跟随等动作等待对话收尾，减少退出与重开时的状态冲突。
- 修复 NPC 主动邀谈的开场接续及失败重试中的部分空白问题；完善确认开战后返回原版战斗的衔接。
- 修复重绘提示词、百科及其他共享文本编辑弹窗中无法输入、确定或关闭的问题；切换百科人物后，旧菜单回调不会误改上一人。

## 三、场景生图：自由取景

- 原自动双机位改为玩家自由取景：冻结现场后自行调整角度，拍摄 1 至 2 张参考图，确认后再生成。
- 操作：W/A/S/D 移动，E 上升、Q 下降，Shift 加速；鼠标转向、滚轮调整视野，Enter 截图，按界面按钮继续或生成，Esc 重新取景或取消。
- 修复取景时的焦点、光标及后台作品保存衔接。参考图提供现场资料，最终构图仍由导演决定。
- 可选环境全景采集超过 1024 个网格副本预算时，跳过该项并继续本次生图，保留已有截图。

## 四、画廊与生图设置

- 画廊支持基于当前选中作品重绘；替换本地默认 PNG 后可点击默认图刷新，需保留配套同名 JSON。
- 画作主题不再按 36 字截短，长说明可滚动查看；修复画风、负面词和导演提示词在重新打开设置或重启后丢失的问题。此前已丢失的内容需要重新填写保存。
- 移除快报内嵌插画的“重绘（基于本图）”按钮；画廊等其他重绘入口保留。

## 五、外交与消息

- 已送达且涉及玩家本国的外国外交文书也会显示右侧通知图标；第三方外交消息使用更清楚的文字区分。删除外交传闻的重复提示。
- 玩家宣言及涉及玩家的外交行动不再套用 AI 外交节奏限制；支持按正文顺序处理多个行动，例如先终止贸易再宣战。仍检查对象、提案来源、条款和实际执行结果。
- 玩家宗主可以通过对话或正式宣言释放直属臣属国独立，无需对方同意；仍需具备统治者身份及直属关系。
- 外交分析采用对应 API 配置的输出预算；遇到输出截断时，不再按同一预算反复自动尝试，保留手动重解析入口。
- 修复部分外交传播与重试互相阻塞的问题，减少重复回应、重复结算和无效请求。

## 六、新闻与其他

- 切换周报/快报模式后重新收集；周报从新周期累计 7 个游戏日。修复新档混入旧结果的部分问题，日期按游戏日历显示。
- YJ 接入引导可测试三条线路并选择成功请求中平均响应最快的一条。
- 修复地图工具栏图标异常放大；政变大厅使用原版攻守部署点；城镇相关说明改为更清楚的操作教程。

## 更新说明

- 单一 AnimusForge 模块，内含 Bannerlord 1.3.x / 1.4.x 两套实现；ONNX 模型仍需单独安装。
- 已完成双版本构建及相关专项检查，尚未覆盖所有真实游戏场景、旧档、第三方模组与外部 AI 服务；接力长度和生成效果仍受模型与场景影响。
- 本次不承诺自动恢复此前已丢失的记忆或修复所有损坏旧档。更新前退出游戏并备份存档。
