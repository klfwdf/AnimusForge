# Native 动作失败处理：制作组短版

这轮修复了一个容易误导玩家的问题：**动作执行出错后，系统仍可能按正常回复继续收尾。**

现在：
- 派发尚未进入动作执行，与执行后结果不明，会明确区分。
- 部分操作已经执行时不会假装全部成功，也不会自动重试整轮、重复扣钱或发奖。
- 日志写入异常不能再让调用方提前结束、队列稍后偷偷执行；重复队列回调也只执行一次。
- 普通输入与 NPC 主动开场都会报告动作未完成，并抑制正常完成提示。

原有业务规则、数值和正常执行流程没改。这里的“未开始”只指本次派发，不能保证前面其它环节没有副作用。

新 59 项定向检查和 6 个变异控制用于验收；准确构建/回归与提交见总 HANDOFF。真实游戏、旧存档和完整事实回执仍需继续，公共 API 仍只读。

本轮只本地修改、测试和提交，没有推送或覆盖游戏。自动化继续。
