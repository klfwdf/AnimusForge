# AF 主体续作：制作组简明 HANDOFF

## 这轮做了什么

修复 Native 对话的两类收尾问题：

1. **动作执行异常不再假装整轮成功**。明确区分「尚未进入执行」与「可能已执行一部分」，不自动重试整轮，避免重复扣钱/发奖。
2. **动作队列一直没被消费时不再无限等待**。30 秒后只取消尚未开始的队列动作；恢复消费后也不会偷偷补做。已经开始的动作仍等待真实结果，不能用超时伪装取消。

日志异常不再改变执行结果。普通输入和 NPC 主动开场都用原展示保护报告失败。原业务 Core、玩法数值、标签规则、制作组模块、存档身份都没改；公共 API 仍只读。
