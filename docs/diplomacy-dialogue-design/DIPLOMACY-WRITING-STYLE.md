# 外交文风简化与验收

本方案经用户确认实施。目标是让公开外交宣言自然、易读，保留人物性格、国家背景和具体交涉处境。实现状态与验证范围以[交付记录](../animusforge-refactoring-and-repository-reorganization-plan.md#local-feature-publication-20261015)为准；本页不改变其他玩家外交设计。

## 写作方式

普通 AI 开场、回应、接力、口头约定拟文和书记官代笔共用一段默认文风提示。允许直接称呼对方、使用“我”“你”、表现骄傲、讽刺、愤怒或克制；是否这样写，由人物、关系和当下局势决定。公开身份不再意味着必须反复以国家或王庭作主语，也不要求每篇宣言使用正式公文套语。

默认写法要求清楚回应对方、表达立场和条件，避免空泛铺陈与刻意追求金句。玩家仍通过原“编辑 AI 外交偏好”入口影响文风；自定义文风优先于默认写法，书记官以玩家原文和写作要求为准。用户已有文件、战略偏好、温度及 API 选择不变。

## 删除与保留

| 项目 | 本次结果 |
|---|---|
| 多处国家主体、公文腔与私聊式表达禁令 | 归并为一段默认写作提示；删除重复风格规则 |
| 按“我/你”等词频判定私聊，并要求改成国家口吻 | 删除判定、三个正则及专门修稿分支 |
| 正文篇幅 | 保留原配置身份、玩家保存值和输出预算算法；新默认100—300字，作为建议，简单答复可短，完整条款优先 |
| 口头约定的区间字数拒收 | 删除；正文完整且在技术容量内即可进入原检查 |
| 6000 字符技术容量 | 保留；普通 AI 与口头拟文都拒收超容量全文，防止静默截掉条款；普通 AI 复用既有一次修稿机会 |
| 外交动作、提案来源、条款和执行 | 保留原协议和校验；按真实立场及承诺判断，讽刺不自动算敌意，客气不自动算接受 |
| 回合推进、退出、死局与收束 | 保留；没有给纯表态新增延长回合的资格 |
| 历史、人物、国家制度与保密 | 保留；文风自由不授权虚构事实或公开私人秘密 |
| 中文/英文 | 固定资源按CN/EN包选择；不追加输出语言锁，模型自然语言由实际上下文和玩家自定义要求决定 |

提示词版本与缓存版本升至 30，复用原迁移流程重建旧的生成和分析请求、清除冻结的旧修稿指令。没有新增存档字段，也不修改已经发布的历史文书。

## 用户验收步骤

以下为覆盖本次构建后进行的实机验收；当前代码交付不等于已经覆盖游戏或完成这些检查。

1. **默认文风**：观察数篇不同统治者的宣言。应直接说出争议、条件和态度，有人物差别；不要求每篇都讽刺，也不要求复现某一句范文。
2. **偏好能生效**：在原外交偏好编辑器加入“简短、直接，可以适度讽刺，不用公文套语”，观察新生成的宣言；再换成“克制、有礼，保留人物个性”。仅比较新文书，已发布历史不会重写。
3. **篇幅是建议**：把建议范围设得较长，再让书记官重写一句明确拒绝。可以短于范围，不应为了凑字数增加条件。长的和平提案则要完整保留金额、期限和方向。
4. **措辞不代替动作**：分别测试“带讽刺的贸易提案”“礼貌但明确的拒绝”“愿继续谈，不接受原条件”。检查实际动作与提案状态，不能把讽刺自动判为宣战，或把礼貌判为接受。
5. **谈判仍能结束**：测试明确拒绝、撤回提案、退出或宣告死局。检查回合按原规则推进与收束，不能靠换个说法无休止延长。
6. **口头协议与保密**：口头谈妥有具体条款的协议，确认发布文本和实际执行一致，私人交谈细节或秘密不会被当作可公开理由。

离线回放能够验证请求接线、动作与状态保护、异常拒收和迁移；文风是否好读、真实模型能否稳定理解含蓄措辞、游戏内体验仍需按上面步骤检查。提示词会影响模型的文本和判断，因此不承诺新旧版本做出完全相同的外交选择或在完全相同的时刻收束。

## 性能与边界

共用提示使用现有延迟加载、进程缓存的资源读取器，仅在请求组装时拼接。没有新增模型请求、二次润色、Tick 扫描、反射、后台游戏对象读取或配置轮询。技术容量检查在生成完成边界执行，原有限次修稿策略保持。

本方案替代旧的“正文篇幅优先于简短文风”要求；保留既有范围外完整稿直接回填、API 输出容量预算和保护玩家原文的行为。没有调整战争压力或国际声誉计算公式。

## AF 终端设置补充（2026-10-14）

外交设置在 AF 终端使用，原 MCM 属性仍负责有效配置的保存。篇幅名称统一为“建议篇幅下限／上限”，新默认为100—300字；已保存的玩家数值保持，恢复偏好文本不会重置篇幅。建议上限还影响书记官的生成容量预算，长稿因容量截断时可以提高本项及 API 最大输出量。

编辑与恢复入口统一使用“外交判断与文风偏好”，代笔说明改为依据玩家原意起草或重写并完整保留条件。事件／叛乱 API 温度说明涵盖外交与代笔，并明确回退主 API 时采用主 API 温度。

六个没有运行读取者的旧设置属性已删除：强制战争开关、战争／和平压力阈值、原版意图／公文影响比例、旧累计 API Token 压缩阈值。真实 MCM 属性发现与 JSON 格式回放验证旧字段可忽略，有效配置保持，重新保存不再写废弃项；没有新增旧字段迁移逻辑。详细状态及构建证据见[交付记录](../animusforge-refactoring-and-repository-reorganization-plan.md#local-feature-publication-20261015)。
