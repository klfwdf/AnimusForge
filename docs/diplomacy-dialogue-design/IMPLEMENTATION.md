# 口头外交模块接入

## 当前传播与顺序边界（2026-10-05）

依用户要求恢复 `cdc8135f`（2026-10-04 20:12）的传播行为：新公开公文按原距离队列进入王庭及民间知识，接力送达仍可使参与国获知同案材料；公开发布不等于全世界立即获知。人物与口头原案查询继续按实际获知范围，已有知识不倒退删除。

玩家回应义务仍持久保留；收到后优先合并本国已有发言，额外优先回应沿原规则不消费接力游标、不取消下一站、不在失败时推进其他国家的顺序。请求仍含同案已获知材料与玩家诉求。并存事件、NPC 单自主发起名额、玩家独立事件、口头承诺独立链路、请求预算、记忆/压缩/缓存与本轮其他修复保持。旧即时全局知识 ADR 0005 已被替代。

[交付说明与验证边界](../diplomacy-round-design/UPDATE_20261005.md)。下列历史验证中“立即公开知识”只描述当时实现，不代表当前传播要求。

口头承诺、修订、控制、来源索引及个人记忆回执由 `AF.Module.Diplomacy/Application/WorldDiplomacyOrchestration.Dialogue*` 与 `PersonalMemory` 持有。纯路由与条款规则位于 `Domain/Dialogue`；稳定存储字段沿用 `_af_world_diplomacy_v1`。World Behavior 只提供实时身份和主线程端口，直接外交标签经模块 Application 分派。根目录旧实现已移除。

## 已接入行为

- 正式宣言使用实际发文统治者的 AF 个人记忆、压缩召回和近期玩家交涉，保留 user/assistant 来源。私人素材只进入作者请求，不进入公共国家历史。发布、实际获知、确认效果分别写入可恢复 AFEF，记忆恢复不重放外交动作。
- 三渠道共享外交话题、运行资格、后处理标签和分派入口。NPC 明确答应后，常规口头外交提交正式公文；双边条约须经正式接受才执行。考虑、报价和犹豫不作为承诺。
- 任何玩家都可劝说当前 NPC 国王，包括劝其回应第三国提案。实际作者及签约方仍是有权国家；玩家公文只能由玩家自己撰写、发布和接受。
- 新事项、不同条件直接创建独立事件，不覆盖或等待既有事件。原案回应按源公文＋动作绑定原回合；多案歧义要求明确来源。查询覆盖所有有效回合，且必须符合实际人物知识和实时条款。
- 普通事件保留原有周期。独立事件共用模块 owner 的生命周期、任务队列、公共知识、玩家机会、结果推进与归档；关闭任一事件不关闭其他事件。玩家手动新公文也有独立归属，回应原案后转回原案事件。
- 正式提案、接受、拒绝支持和平、同盟、贸易、吞并、朝贡、驻军和完全臣属；NPC 宣战、解盟、取消贸易先发布正式宣言。吞并／臣属显式记录接收／宗主国与并入／臣属国，允许合法的 AI—AI 和玩家—AI 任一方向。
- 臣属条约复用原协议库、贡赋、服从度、战争与和平同步。非玩家宗主的军事臣属也持续维护，驻军与完全臣属不能自主宣战；朝贡保留原有自主与保护规则。吞并复用原家族／领地转移机制，部分交割失败不会重放已发生转移。
- 原国王未公开的承诺在死亡或失去统治权后终止；继任者不继承。已发布公文按国家规则处理。明确延期保留原因，技术重试与主动延期分开；取消已公开未接受的自己提案会发出正式撤回宣言。已生效行动不能用私人谈话回滚。改条款建立新事件，不修改原案。
- 保留玩家国王亲自口头宣战、独立玩家家族即时停战两个例外。

## 存档与运行频率

`ConcurrentRounds`、`DialogueArrangements` 是 `_af_world_diplomacy_v1` 中的可选字段；不新增外交存档 owner。存储稳定身份、版本、原国王、原案、公文及结果，旧档缺字段使用空集合。约定去重和文书发布回执防止重复建事件和重复效果。

个人检索只在构建宣言请求时运行，最多 12,000 字符，压缩召回最多六块并服从 MCM 数量。原案索引按请求使用并在变更／载入后失效，不逐帧扫描世界与个人历史；显示候选上限不影响真实唯一性判定。发文技术恢复每日最多四项；主动延期不自动恢复。臣属维护按外交事件和每日运行，每次复用国家敌人快照；生命周期沿用既有外交调度节奏。尚未测量 live game 耗时。

口头达成的确定条款使用结构化模板公开，不再让第二次 LLM 生成改写条款；私下理由不写入该公开正文。自然外交生成和玩家公文解析继续使用现有请求链。

## 计划复核后的补齐

- 未公开改约必须携带 `supersedes`、原 `version` 和明确 `reason`。验证原国王、当事国、动作、旧版本及当前未公开状态；新条件通过校验并拥有独立事件后，旧安排标记为 superseded，保留双向版本来源，旧事件终止。遗漏明确来源、旧版本不符或其他国家的安排均不能取消旧约定。相同事项有不同未公开条件时，缺少修订引用会要求明确来源。晚到旧文书在实际分析入口被拒绝，不能发文或执行效果。已公开提案仍须正式撤回，再提出新方案。
- 三渠道在实际同步动作入口采集私人交涉来源：渠道、会话、实际 trace 或旧链路独立 turn 回执，以及有界玩家／NPC 原话。来源 ID 与条款去重 fingerprint 分开；嵌套旧吞并／臣属适配保留同轮来源。旧存档来源不明时明确保留 legacy_unknown，不伪造渠道。私人来源不进入公开公文。没有外交动作的普通聊天不创建来源对象或额外清洗正文；scope 不跨 await 或队列，场景排队携带不可变来源。
- 接受、改约、取消、延期、恢复及技术失败先保存不可变记忆种子，再提交 AF 记忆 owner。保存原始来源、人物、事实、日期、小时、称谓和场景，跨日重试不改变提交内容。不可用或拒绝时保留失败原因及待恢复回执；Applied／Duplicate 或 AF 已接收持久种子后交由原记忆 owner 恢复。每日最多四个安排、八条事实，读档重建临时队列；未提交的事实不会因旧安排归档清理而丢失。恢复不调用发文或外交效果入口。
- 控制操作保存独立递增回执；相同处置重复提交不增记忆，延期→恢复→再次延期或原因改变使用不同来源，避免同 ID 内容冲突。已发布但私人状态尚未更新的故障按公文真实回执恢复状态，不当作尚未公开承诺取消或重新执行。场景延后动作判定也已包含正式外交标签。

## 验证与边界

- `DiplomacyDialogueRoutingTests`：82 项路由、条款、修订、来源预算及结果合同检查通过。
- `DiplomacyDialogueMemoryTests`：18 项个人材料、身份及角色边界检查通过，直接使用当前记忆模块材料 owner。
- `WorldDiplomacyRoundLifecycle.SmokeTests`：3,414 项默认回归；`--concurrent-oral-migration` 64 项真实 Application 回放，包括从口头提交到公文发布、提案登记和立即公开知识。双边提案未被接受前不执行条约；私人原话不进入公开正文。
- `WorldDiplomacyResultSettlement.SmokeTests`：573 项回归通过；旧单回合恢复断言改为遍历所有活动事件，结束及结算资格保持原规则。
- 所有权负向检查 63 项通过；1.3、1.4、Bootstrap 使用原脚本构建通过，零编译错误。

主对话和后处理从模块读取同一约定 ID、原公文及版本上下文；后处理使用上次设计的 COMMIT／COMMITMENT 标签。自由对话、场景喊话、信使同步动作入口采集同一来源结构，排队动作携带不可变来源，scope 不跨 await。

这是模块源代码和离线合同证明。真实模型、真实战役效果、三渠道游戏交互、实际存读档和缓存命中率尚未实机验收；未推送或覆盖游戏。
