# 公开外交知识即时可查，沿用既有记忆与缓存边界

2026-10-04，用户选择公开公文立即成为全世界可查询的公共知识，去除距离传播对回应的等待，以改善外交速度和玩家回应体验。这替代既有方案中“公开原案尚未传播到达就不能正式回应”的距离送达前置条件；正式原案的存在、权限、未决状态、条款及实际执行合法性仍必须核验。公开知识不表示所有国家都必须发言，发言对象和顺序另行决定。

私下交涉、私人承诺与受保护材料继续使用已有口头外交边界，不因即时公开知识而全世界公开。公开公文仅使用允许公开的内容；玩家转述仍是有来源的说法，不能转为系统确认结果。沿用现有共同外交历史、个人记忆、压缩、来源去重和共享前缀设计，不以并存事件为理由拆出新的长期记忆库或每事件独立压缩；实施时须验证共同前缀与压缩恢复，并单独测量实际缓存表现。
