# 玩家优先发言推进同一场外交交涉

用户确认：玩家插入已有外交回合后，相关国家要回应这次发言，其他国家随后接着更新后的交涉继续。三类请求队列区分处理优先级，不区分公共交涉上下文；玩家优先回复不能成为 AI 普通交涉之外的旁路。尚未开始的同国发言应更新并合并，避免普通回复和玩家回复重复生成；已发布回应写回原事件并影响后续发言材料与顺序。

跨事件允许并行，同事件后续发言依次生成，以保持相互承接。在途旧请求按已确认适用性规则处理，未读到新玩家发言的结果不能视为已答复。该决定调整回合调度，不增加玩家发布拦截，也不改变公文内容、多动作、提案、外交效果、记忆压缩及原结束机制。原事件关闭后的未答复由引用原公文的优先后续事件承接，不复活旧协议；具体预算数值作为工程默认值记录在并存调度实现文档。
