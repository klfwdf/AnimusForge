# 用共用提示与玩家偏好控制外交文风

外交宣言应像有具体身份和利益的统治者在回应对方，允许自然人称与情绪。此前分散的国家主体、公文腔、词频拦截和字数优先要求容易压平人物差异。

采用一段中英成对的默认写作提示，由现有外交偏好覆盖默认措辞；普通生成、接力、口头约定和书记官共用。删除私聊文风启发式判定，将正文长度改为建议。事实、保密、JSON、合法动作、条款来源、回合收束及技术容量仍由原功能规则保障。语义分析依据真实立场与承诺，不能用讽刺或礼貌替代动作判断。

不新增温度滑块、模型请求或文风重写层。选择这一方案是因为温度只能调节采样随机性，无法明确表达人物口吻和玩家写作要求；继续叠加词频或公文格式校验会重新增加文风限制。

本决定仅替代外交文风及书记官“篇幅优先于简短”的旧要求，不替代玩家外交独立推进、公开与私密素材边界、已执行事实等决定。提示词变化可能影响模型具体选择，离线状态回放不等于真实模型文风或实机验收。实施及验收见 [DIPLOMACY-WRITING-STYLE.md](../../DIPLOMACY-WRITING-STYLE.md)。
