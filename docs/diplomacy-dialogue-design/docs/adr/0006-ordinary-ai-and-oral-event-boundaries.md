# 普通 AI 发起名额与口头承诺事件分别管理

2026-10-04，用户提出：NPC 自主主持的贸易等普通 AI 回合，和因答应玩家而形成的口头外交事件，可以保持独立链路。按事件来源区分发起名额，使每国最多一个自主发起事件，同时保留既有口头新事项立即独立建案的体验；参与他国事件不占本国自主发起名额，玩家宣言也不受该限制。用户后续确认该方向，并授权与并存调度一同实施。

独立的是事件归属、生命周期和发起名额，外交执行、世界状态检查、存档及记忆仍共享同一体系。接受或拒绝具体原案仍进入原案事件，不因口头来源创建重复协议；新事项保持独立，重复承诺去重。共同历史、压缩和缓存边界继续沿用。口头特殊事件共享总预算，政策事件按普通事件归类，自主发起名额在事件按原规则结束后释放，不通过一国一个普通回合推导无限生成额度。
