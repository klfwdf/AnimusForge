# 接受建议创建新回合，玩家保留正式发文权

统治者明确接受一项新的、需要经宣言处理的外交建议后，为这件事直接创建新的外交回合；不等待正常外交周期。重复确认同一安排不创建相同新事件。回应已有正式原案则进入原案所在回合，提出不同条件才创建新事件；不能仅因两国相同就复用相关回合。用户允许玩家即时口头宣战和独立家族停战作为例外。用户另行计划多回合共存的底层改造，这属于外部依赖，不在本口头外交功能设计任务中重建，也不能通过覆盖旧事件或默默排到旧回合结束来替代。

玩家的正式外交宣言只能由玩家自己发布，系统不得代写。玩家为国王并与另一位国王口头谈妥和平条件时，由对方国王创建新回合、正式提出约定条件，再等待玩家正式接受。这样让口头谈判进入公开外交，同时保留玩家的正式发文与接受权；系统不得把私下同意当成已经正式接受或已经达成和平。

## 2026-10-03 后续实施决定

用户在此前部分实现后要求“做完”，并继续要求“继续跑”。为了交付完整口头约定链路，本次补齐其必需的独立事件能力：原 owner 保存并存回合、统一推进与归档，并按原案身份查询和路由；保留主回合正常周期，不覆盖其他事件。此决定替代上文将必要能力作为未完成外部依赖的实施边界；更广泛的外交底层重建仍另行处理。玩家发文权及新事项／原案回应规则不变。
