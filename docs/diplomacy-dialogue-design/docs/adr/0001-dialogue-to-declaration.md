# 口头外交通过记忆和明确安排衔接宣言外交

宣言已读取人物背景与外交档案，但缺少统治者个人交往记忆；现有口头外交还能直接执行部分行动，造成交涉与宣言过程不连贯。设计采用两种互补入口：日常交涉进入个人记忆并影响未来判断，明确接受的具体事项形成外交安排并进入宣言流程，同时改造既有口头外交以遵循这一方向。

只注入记忆能够改善人物连续性，却不能稳定承接已答应的事项；将每次考虑都转化为强制行动又会混淆建议、承诺与已发生事实。因此保留这些语义区别，并让正式发布、对方回应及执行结果各有明确阶段。

明确承诺原则上落实；重大局势变化或条件未满足时允许延期、修改或撤回，并记录原因。私人材料用于决策，私下交涉细节默认受保护，明确保密的信息不直接公开。新回合与玩家发文边界见 ADR-0002，完整生命周期和验收约束见 DESIGN.md。

用户进一步确定一次覆盖现有国家口头外交动作，并将国家吞并、朝贡、卫戍和附庸接入正式宣言外交，支持宣言本身促成这些行为。玩家有权亲自当场口头宣战与独立家族停战保留即时例外；玩家劝 NPC 接受未来宣战安排则走宣言流程。
