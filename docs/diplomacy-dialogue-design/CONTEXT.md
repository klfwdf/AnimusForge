# 外交对话与宣言衔接术语

本术语表服务于 AnimusForge 外交对话与宣言衔接设计。以下术语依据玩法访谈确认，工程接口与状态实现见 DESIGN.md。

## Language

**口头外交**：
玩家与人物交流中涉及国家关系、外交立场或外交安排的交涉。交涉中的建议、表态与已达成的外交结果需要分别描述。
_Avoid_: 将所有外交对话都称为已达成协议

**外交宣言**：
以王国名义公开发布、可被其他国家获知和回应的外交公文。
_Avoid_: 将私下表态直接称为公开宣言

**统治者个人记忆**：
这位人物自身经历以及与玩家交往的记忆，包括与当前议题相关的私人经历、情感和私人承诺。
_Avoid_: 用外交档案代指个人记忆

**外交档案**：
记录公开外交公文与外交结果的历史材料。
_Avoid_: 用个人记忆代指外交档案

**已执行外交结果**：
已经实际发生的外交状态变化，区别于建议、意向、承诺和等待答复的提案。
_Avoid_: 用答应或愿意证明外交结果已经发生

**外交劝说**：
玩家通过交流尝试影响统治者外交判断的行为。能够提出建议不等于拥有代表国家订立协议的权力。
_Avoid_: 将劝说资格与国家签约权混用

**外交安排**：
统治者明确接受、等待通过外交宣言处理的具体外交事项。它区别于仅供考虑的建议，也不表示对应外交结果已经发生。
_Avoid_: 将“会考虑”称为已接受的外交安排

**私人外交承诺**：
统治者对玩家作出、尚未公开为正式外交公文的承诺。它属于玩家与该统治者的交往，不由继任统治者继承。
_Avoid_: 将私人承诺当作已成立的国家协议

**外交回合**：
承载一件外交事件及其正式交涉进程的单位。新事项建立新回合，对正式原案的回应归入原案所属回合。
_Avoid_: 将外交回合当作固定天数的全局外交周期

**外交回合发起国**：
开启这件外交事件的国家。其他国家在事件中回应或加入交涉，不因此成为该回合的发起国。
_Avoid_: 将每份公文的作者都称为回合发起国

**外交回合参与国**：
在某件外交事件中参与交涉的国家；参与身份不等于发起身份，同一国家可以参与不同事件。
_Avoid_: 将参加别国事件称为本国另开回合

**普通 AI 回合**：
由 NPC 国家自主发起的外交事件，区别于玩家宣言和玩家交涉促成的口头承诺事件。
_Avoid_: 将 NPC 发出的所有外交公文都视为自主开案

**口头承诺事件**：
由统治者明确答应玩家的一项新外交安排形成的事件。它与该国自主发起的外交事件分别承载交涉；回应既有正式原案仍归原案事件。
_Avoid_: 将口头承诺独立成与国家外交无关的协议或记忆体系

**公开外交知识**：
正式公开的外交公文及已确认外交结果，供世界中的人物和国家查询。公开说法与实际发生的结果各自保留其性质，不包含未公开的私人交涉。
_Avoid_: 将私下承诺或公开转述视为已经执行的国家协议

**口头约定**：
双方私下交涉中确认的拟议条件。涉及玩家王国时，口头约定不能替代玩家在正式外交中的接受。
_Avoid_: 将口头同意称为正式接受或已执行协议

**即时口头宣战**：
玩家以有权身份通过口头交流当场宣布并执行的宣战，不要求先发布外交宣言。
_Avoid_: 将未来宣战安排或考虑宣战称为当场宣战

**正式提案**：
已经公开提出、具有明确提出方、受案方与条件、等待正式答复的外交方案。
_Avoid_: 将未公开的口头约定称为正式提案

**原案回应**：
对一份具体正式提案作出的接受或拒绝，归属于原案所在的外交事件。提案是否由玩家提出不改变这一归属。
_Avoid_: 仅因国家相同而把不同外交事件当作同一原案

**外交斡旋**：
玩家劝说一国统治者回应另一国提案的交涉。玩家是劝说者，不因此成为正式协议的提出方或接受方。
_Avoid_: 将第三方劝说称为代表受案国签约

**国家吞并**：
经双方正式同意，一国失去独立国家身份并整体并入另一国的外交安排。
_Avoid_: 将保留独立国家身份的臣属称为吞并

**朝贡国**：
以贡赋换取宗主保护、保留军事自主权且不承担臣属出兵义务的国家。
_Avoid_: 将所有臣属统称为朝贡国

**卫戍国**：
承担出兵义务、不承担贡赋义务且没有军事自主权的军事臣属国家。
_Avoid_: 将卫戍国与朝贡国或附庸国混用

**附庸国**：
承担贡赋与出兵义务、外交及军事受宗主控制的臣属国家。
_Avoid_: 完全附庸国；将普通家族归附称为国家附庸
