# 快报事实长期保存与NPC检索实施方案

## 范围与行为

本轮实现快报事实档案和三渠道共同的请求级RAG，不重写个人对话记忆、玩家近况16条、世界书或外交传播机制。报刊成稿、私聊候选、模型轶闻不能成为事实档案来源。

1. 在现有 `_af_worldBulletin_v1` JSON 内新增可选事实档案；重大已确认事件在采集时保存，不依赖自动出版，也不随8日窗口裁剪。事件稳定key去重，修订更新原记录。
2. 旧档一次接回仍保留的事件，以及历史快报/残余记录中明确标记的事实材料。不能将旧周报正文、文学成稿或无来源摘要拆成事实；缺失身份不猜测补齐。
3. 请求主线程捕获观察者身份、所属/所在地王国、已知外交文书ID。先过滤权限，再构造脱离游戏对象的候选：亲历者、相关地区公开事实、已出版的重大公开新闻；外交始终必须有文书知情权限。
4. 复用ONNX embedding进行语义召回，再复用cross-encoder重排序。人物/地区/词项索引缩小范围，候选最多48条、重排最多12条、最终最多4条；按事件组去重。日期保持游戏原值，旧事不冒充现状。
5. 标准Scene/Native/Courier捕获→worker→应用结果路径共享实现。模型不可用时显式记录降级，使用已过权限过滤的词项匹配；不能借降级扩张知情范围。请求过期不注入。

## 性能与兼容

- 无新HTTP请求、Tick IO、Tick全量扫描或后台游戏对象读取。索引随档案变更更新；已有ONNX缓存复用，单请求候选/推理/正文均有上限。
- 长期重要事实不因年龄或摘要成功而删除，存档增长属于保留事实的真实代价；不以截断事实制造安全。沿用12000 UTF-8字节分块与损坏保存边界。
- CN/EN固定说明同任务接线。旧档缺新字段可正常加载；无法恢复的旧细节明确不补编。保留原周报与近期简讯、既有报刊轶闻语义。

## 退出门

- 当事人、本国/当地、异地陌生人、未知外交文书、不同日期的同类事件和同组事件的筛选回放。
- 一游戏年后及保存重载，旧事实仍可按人物/地名/话题取回；大量新事件不得仅因时间更近挤掉精确匹配。
- 真正embedding与reranker适配有可执行接线；可控评分器验证排序，实际本机模型可用性单独报告。
- 三渠道共享捕获/worker/应用/最终注入；格式、有限预算、语言与过期边界验证。
- 分块专项、原双API/Bootstrap构建、相关快报回归；实机与真实回复效果单列，不由离线回放代替。

实际提交、结果、未验项记唯一主台账与HANDOFF。仅本地开发/构建；不部署、打包或推送。
