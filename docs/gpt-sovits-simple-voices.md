# GPT-SoVITS 简版：按性别随机与角色固定音色

状态：源码与离线验证完成；未部署、未进行游戏内实测。翻译/指定朗读语言仍未实现。

## 使用入口

1. MCM 的“7. 语音输出”中开启 TTS，再开启“使用 GPT-SoVITS（关闭则使用火山）”。默认关闭本地来源，原火山设置保留。
2. 下方 GPT-SoVITS 栏填写本机 API（默认 `http://127.0.0.1:9880/tts`）和语音包 `manifest.json` 路径。本机已有包为 `D:\AF-TTS\manifest.json`；代码不硬编码此路径，留空则读安装模组的 `VoicePacks/manifest.json`。
3. 本机服务需要事先手动启动；模组不自动加载模型。语速和本地测试按钮在同一栏目。
4. 打开有名 NPC 的人物百科，点击“选择声音”。无需开启开发者编辑模式；只显示同性别声音，可手选或“随机抽取并固定”。这里不修改个性/背景或正文语言。

## 分配规则

- 有名角色使用 Bannerlord `Hero` 身份，包括领主、同伴、要人等。玩家没有选择时，首次请求语音按性别抽取，并写入当前战役角色资料；之后保留同一个声音 ID，随存档保存/读取。
- 普通士兵、平民等非 Hero 按性别随机，当前场景同一 Agent 保持音色，离开场景后不永久绑定。升格成为 Hero 后采用有名角色规则。
- 本地音色独立字段 `NpcPersonaProfile.GptSoVitsVoiceId`，不覆盖火山 `VoiceId`。重生个性背景保留两种音色。
- 清单调序或加新声音不会改变已固定 ID；固定声音被删除或性别不符时不偷偷重抽，回退文字，玩家在百科重新选择。
- 首版只按男女分，不按年龄、文化或语种限制角色。朗读原正文，输出语种用 `auto`；参考录音的 `prompt_lang` 独立，不自动翻译。

## 传输、资源与限制

- 单一本机 HTTP 请求、完整 WAV，沿用原 TTS 队列、请求身份、口型、音频和取消消费者；不需要假 Token/AppID，不转发火山凭据，不自动重试或切付费云端。
- 本地参数单批次，关闭 CUDA Graph；客户端超时180秒、单条正文上限500字符、参考文件8 MB、响应32 MB。超过范围或服务/参考失败仅回退文字，不截断台词冒充完整朗读。
- 真实野战、攻城与出城战禁用本地语音，取消本地排队/进行中请求与播放；不把所有 `Mission.Mode.Battle` 当真战斗，以免误伤战后处置/城镇独立场景。原火山行为不改。
- **没有自动停止或卸载外部 Python 服务。HTTP取消不保证服务端立即停止推理。** 为释放显存仍需手动停止自有服务；不杀用户或其他工具拥有的进程。
- 当前 D 盘参考包定义20男/15女；来源/哈希可读，但不是所有音色都已合成/听感验证。部分中文录音仍为44.1 kHz；旧环境已知缺少可选 `resampy`，对应声音可能返回400，需要以后明确批准补依赖或制作推理副本。本轮不改 G 盘推理环境或 D 盘资料。
- 既有16 GiB机器曾在独立试音中触发内存保护；源码编译/离线请求通过不等于与游戏共存稳定。不要把战斗禁声等同于模型不再占显存。
