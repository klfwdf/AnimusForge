# 文本与消费契约

## UI 与模型正文分开

- 同一 catalog 含 UI、Prompt、事实时，按消费者用途读取：UI 当前界面语言、Prompt 固定包语言、兼容原值稳定。不能整文件统一换成某一种入口。
- 优先复用现有 TextObject 和两套 XML。英文 fallback、中文注册、资源 ID 和变量同步；缺翻译仍可回退英文，不能把空值当成功。
- MCM 的 Name/Hint/Group、静态属性、构造器元数据、终端字典、实际 helper 和 fallback 都是消费者。只改 XML 可能仍显示旧说明；数值、范围、默认开关、委托、资格和路由保持。
- Gauntlet 固定文字应绑定真实 DataSource 文案属性；主 VM 和每行 VM 分别核实。按钮显示正常但 Text 绑定不存在、错作用域或宽度容不下英文也属于缺口，不能只检查资源键存在。
- 物品/装备 XML 的固定名称使用 `{=稳定键}English fallback` 并登记中英资源，保留物品 ID、mesh、flags 与数值。可分发 XML 新注释用英文；旧注释与实际漏译分别分类，门禁拒绝时做保结构修复，不整文件豁免 prefab。

## 动态模板与原值

- 动态人名、玩家文本和已有模型原文不能被 `{NAME}`、`{0}`、`$1` 再次解释。原生 TextObject 先选语言再做安全字面插入，复用项目已有 named-slot 格式化；正则动态替换用 MatchEvaluator。避免连续 Replace 递归改插入值。
- 模板变量只绑定一次，空串与 null 保持原语义；不同契约拆键，不能中英同键却传不同变量。const、默认参数和 case 不能直接调用 reader，按原语义改为惰性属性、入口默认或等价分支。
- 兼容词、正则、否定/肯定词、历史标记和旧错误匹配保原值、顺序、大小写及意义；英文识别路径需保持。错误匹配/重试用 raw，最终 UI 投影双语。
- 新技术诊断英文但不删异常、目标、阶段和原因；共享静态默认值的迁移不得使无关纯函数提前发生磁盘 IO。

## 事实、历史与存档

- 存档键、类型/程序集、JSON 字段、枚举值、标签及 AFEF 身份不随语言改名。旧中文稳定事实可保值外置，UI/Prompt 在各自边界投影，不批量改写旧存档。
- 区分已执行、请求、失败、取消与未确认。保留 actor/target、原因、金额、次数、时间、来源和因果；编辑/删除历史仍使用原始记录身份，不能按译文定位保存对象。
- 带人物名的 AFEF speaker/前缀进入 UI 时按已知记录 kind 和可信结构投影，不猜译人物名，不把整个兼容标记当成用户可见自然语言；显示副本与保存/解析原值分离。
- 日期、政策目标和数量用已有 typed 信息或精确已知 canonical 分支。不根据任意名字中的“发布地”、标点、“另若干处”等拆动态名字。未知、歧义、重复或不完整包装保原值，除非已证实生产格式。
- 周报/历史用于请求时只投影脱离保存对象的副本，保持 DTO 元数据。信使、自由对话、喊话的角色、事实、历史和执行语义一致，读取仓库三渠道案例处理有关变更。

## Prompt 与覆盖配置

- 两套正文同时完整存在，包选择用原标准文件名，`.en.json`/`.en-US.json` 等按实际选择器投影，不在运行时猜测语言。
- role、历史顺序、预算、上下文资格、字段、协议示例、变量、否定与权限保持。英文不得要求中文输出；字符预算不能改成单词数，也不修改数值或机制。
- 核对真正主请求：legacy 字符串、JArray/messages、provider 序列化和最终系统规则。英语资产存在或玩家输入英文不证明实际回复语言；历史和用户覆盖可能改变请求。
- 在最终 system 明确按包语言生成新的自然语言字段：对话/信件、标题/公报、记忆、人物背景、政策原因、命名及插画文字。复用 `PromptComposerTexts.ApplyOutputLanguage`，在可编辑规则之后收口；JArray 先 clone，重试不能重复追加或修改玩家输入。通用合同抽取/哈希和纯标签、数字、JSON字段、稳定协议仍保持原契约。
- 附加规则块、AFEF 等分隔标记是协议；不能因 EN 包翻译其 prefix 而让 topic 检测或后处理脱节。原生标签、MCM 下拉显示与终端缓存必须核对当前界面语言及实际 DataSource；显示投影不改变选择索引或保存身份。
- 迁移旧默认只能按可信旧值/版本身份识别，真正用户自定义不能静默覆盖。记录当前来源与优先级；默认 CN→EN 切包需要实际请求验证，不能只验证磁盘默认文件。
- 不让英文缺文件静默回退中文；产品沿原失败语义报告，测试提供真实包资源。固定中文协议可以原值插槽加入双语正文，不翻译协议来绕过下游解析。
- 知识检索保原 cue/权重/门槛与预算；英文词边界和词形核对真实输入，不删除 a/I/s 等动态原文字母。最终答复语言、匹配和机制接受分开验收。
- 通用称谓与实体名分开。若已证实 `lords` 经内部 ID 子串误命中人物，应在共享匹配边界做窄限制并保真实显示名、限定人名与完整 ID，不能全局删除英文提及或影响 Lore 词条检索。

## 模组数据与固定默认

- 复用 `AnimusForgeDataPaths` 定位当前安装模块；提示词在 `CustomPrompts/`，日志在 `Logs/`，设置在 `Configs/`，世界书导入导出在 `PlayerExports/`，缓存/音频在 `Cache/`，恢复资料在 `Recovery/`。按用途维护，不把全部运行资料塞进一个 Cache。路径创建和返回前后校验完整 ancestor/reparse，避免旧目标文件存在时跳过校验。
- 包默认文件映射到 `ModuleData/Defaults/CustomPrompts/`，用户文件不作为包默认映射。旧发布文件只按精确受信哈希清册识别；未知、编辑、空值和坏文件的处理保持已有语义，不能凭中文/英文猜测是否用户文件。
- 用户覆盖优先；兼容导入的旧用户文本保原字节，已有模块用户编辑优先于旧位置。不静默删旧 C 盘资料。`McmKnownPromptDefaults.json` 同步记录两种默认资产的精确 SHA，切包与升级验真实 reader 的优先级和最终请求。
- MCM 持久化仅路由 AF-owned IDs；沿用真实 formatter、preset 身份与字段。校验未知模组隔离、既有模块优先、坏 UTF8/JSON、原子写入及 junction 阻断。不得把目录改名当成数据迁移已经通过。

## 世界书

- 使用真实路径/身份映射；英文改名、旧索引未命中不等于缺译。包内保原读取路径/存档身份，显式映射 EN Id 后检查引用。
- 同 HeroId 只有正文确实相同才可无损共享；不同正文分别保对应资产，不伪造新身份或删差异。独立无中文对应的 EN 资产单列。
- 审校主体、亲属/敌友、条件/否定、数字/单位、时序、性格和因果。JSON/变量一致、没有汉字和映射 valid 只证明各自结构，不能证明语义完成。
- 全量交付覆盖全部应交付资产；抽查只作发现风险，不能把未经审查的剩余部分写为已通过。
