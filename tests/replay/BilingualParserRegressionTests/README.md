# Bilingual parser regressions

`python -X utf8 -B tests/replay/BilingualParserRegressionTests/run.py --run-root artifacts/<new-directory>`

The runner extracts exact current production method spans, compiles the actual compatibility/package readers, and runs the same CN/EN positive and negative cases in separate package processes. `--source-ref <revision>` runs an immutable old-source negative control. Inputs and one-based source spans are hashed. No credentials or game installation are needed; the existing net6/netstandard Newtonsoft assembly can be selected with `--newtonsoft`.

Coverage: public peace-term disclosure including actor/recipient direction and amount/duration, diplomatic topic categories, empire identity checks, policy bottom/top cardinality, and auxiliary overheard history recognition. Module-path selection and the policy branch's two data fields are fixture leaves. This is not a live game, provider, complete target-selection pipeline, or all-three-channel integration test.
