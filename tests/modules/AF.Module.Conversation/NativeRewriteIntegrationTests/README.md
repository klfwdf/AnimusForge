# Native rewrite integration regression

`run.py` links the production native rewrite adapter, receipt and overlay repaint partial unchanged. Bannerlord identity/audio/localization/UI leaves are controlled fakes. It checks new-turn retirement, pending and failed turns, native/scene speech guards, presentation/save/target changes, exact-source rejection, one-shot rewriting, original input restoration and UI generation retirement.

This fixture does not represent a real Bannerlord UI, provider, action execution or save load. Memory owner capture and real game acceptance are separate checks.
